## 官方博客

**Claude Blog：New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration**

Anthropic 为 Claude Managed Agents 推出三项重要更新：

**Dreaming（梦境记忆）**：定时回顾历史 agent 会话，提炼模式、精简记忆，让 agent 跨会话自我进化。开发者可选择自动更新记忆，或先审查再落地。Harvey（法律科技公司）接入后任务完成率提升约 6 倍。

**Outcomes（结果导向）**：开发者写明"成功标准"的评分标准，grader agent 在独立 context window 中评分（不受主 agent 推理过程干扰），未达标则 agent 重做。内测显示任务成功率最高提升 10 个百分点，docx 文件生成质量 +8.4%，pptx +10.1%。

**Multiagent Orchestration（多 agent 编排）**：主 agent 将任务分解后委派给各专项子 agent 并行执行，共享文件系统，全流程可在 Claude Console 中追踪溯源。Netflix 平台团队已用此方案并行分析数百次构建日志，自动定位跨系统的共性问题。Spiral by Every 的写作 agent 用 Haiku 做编排、Opus 做写作，并用 Outcomes 强制执行编辑标准。

https://claude.com/blog/new-in-claude-managed-agents

## PODCASTS

**Unsupervised Learning：Ep 87 — Gemini 联合负责人谈 World Models、RL 的下一个战场与持续学习**

**核心观点：** AGI 某种程度上已经到来，但模型仍缺乏真正"从经验中学习"的能力——这是 Oriol Vinyals 认为当前最重要的未解问题。

Oriol Vinyals 是 Google Gemini 的联合负责人（与 Noam Shazir、Jeff Dean 并列），深度学习领域的先驱，Seq2Seq、Pointer Networks 等奠基性工作的作者。以下是他在 Google I/O 后一天接受采访时分享的核心洞见：

**World Model 的本质**：Omni 之所以称为"世界模型"，不仅能理解多模态内容，更能在语言控制下对世界进行精确渲染和交互式模拟——包括机器人等应用的规划预测。但他坦承，纯视觉表征学习（不依赖文字标注）的"视频 GPT 时刻"尚未到来，核心难题是如何在没有语言锚点的情况下从图像/视频中抽取有意义的概念。

**RL 的下一个战场**：RL 的优势在于"数据复杂度自动扩展"——下棋时走几步就进入全新局面，训练数据近乎无限。LLM 的 post-training 尚未找到等价的无限复杂度数据源，而这正是当前最大的研究瓶颈。他比"更好的数学/代码能力"更感兴趣的是 meta 能力：模型能否真正从经验中高效学习、能否适应全新游戏规则而不只是调用记忆。

**记忆系统的未来**：他用计算机的 cache/L1/L2 类比 AI 记忆层次——当前 context window（工作记忆）已经很强，但跨会话的"情节记忆"仍依赖文件系统式存储。这种非参数化记忆机制他认为将成为下一个范式转变，正如一年半前推理模型的崛起。

**对创业公司的建议**：不一定要自训模型，但要极度重视 evaluation 体系和领域数据积累——这些资产的价值丝毫不亚于模型本身。

"如果七年前让我试用我们今天的模型，我会宣布 AGI 已经实现。"
