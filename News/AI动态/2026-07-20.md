### The MAD Podcast with Matt Turck — Stripe's AI Chief: How AI Agents Will Buy, Sell, and Pay

**一句话核心：** AI agent 正在重塑商业的基础设施，而 token 盗窃是目前最被忽视的安全威胁。

Emily Sense 是 Stripe 的数据与 AI 负责人，也是 Stripe 押注 agentic commerce 这个方向的核心人物。她提出的几个洞察颇具份量：

**Token 盗窃规模超出想象。** 欺诈者已经发现，AI 时代不需要盗取钱或账户凭证——只需要盗取 token。Stripe 的数据显示，**AI 公司超过六分之一的新注册是这类滥用行为**。她将其称为"token 版的吃霸王餐"（dine and dash for tokens），是她认为整个行业最被低估的话题。

**Agentic commerce 是一个连续频谱，不是单点。** 从"agent 完全自主地发现服务、决定购买、完成交易"，到"用户在 AI 界面里搜鞋子然后点一下买"，这中间有很多层次。Stripe 用类似自动驾驶 L1-L3 的框架来描述这个谱系。目前消费者大多停留在 L2——把部分选择权交给 AI，但不会把整个夏季假期的预订一键交出去。

**ACP（Agentic Commerce Protocol）想成为 agent 世界的 MCP。** Stripe 与 OpenAI 联合创建了这套协议，让商家只需一次接入，就能被所有支持协议的 agent 发现和调用。Wix、Shopify、Best Buy、Coach 等已陆续接入。协议是支付处理商无关的——不绑定 Stripe 也能用。

**Agent-to-agent 商业是未来，但今天还没有。** 当买卖双方都是 agent 时，发现、定价、谈判、整合的效率将大幅提升。但 Emily 坦承，这目前仍是未来场景。

**"它不是 Emily 授权 agent 代她购物。而是 Emily 有一个 agent 负责运营一家公司，这包括买一些东西、卖一些东西、赚一些利润。"** 这是她对 12 个月后希望讨论的世界的描述。
