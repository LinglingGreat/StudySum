**Claude Blog**：《为 Apple 平台构建智能应用：在 Foundation Models 框架中使用 Claude》

Anthropic 发布新 Swift 软件包，让苹果开发者可以在 Apple 的 Foundation Models 框架内直接调用 Claude，处理多步推理、代码生成等复杂任务。Apple 的 Foundation Models 框架本身极易上手，最少三行代码即可通过 guided generation 返回类型化 Swift 值——开发者可用它调用本地模型完成轻量任务，再将复杂请求转交 Claude。

典型场景：记录应用在本地生成每日提示，再交给 Claude 梳理数月日记中的主线；学习应用本地解释术语，用户追问时转给 Claude 做深度关联——对用户而言无缝，背后是按需切换的合适模型。

该包明日上线，支持 iOS 27、iPadOS 27、macOS 27、visionOS 27、watchOS 27，使用 Anthropic API key 即可。

## PODCASTS

**The MAD Podcast with Matt Turck**：《如何构建长周期 AI Agent——Mitch Troyanovsky，Basis》

**核心观点**：100 个 eval 全通过，不代表 Agent 在生产中可靠——过程比结果更重要。

Basis 联合创始人 Mitch Troyanovsky 系统拆解了构建长周期自治 Agent 的底层逻辑。Basis 做的是端到端会计自动化，核心挑战在于：一份复杂报税表需要数千步推理、数百份文档，耗时可能超过 20 小时。这让 Basis 成为非编程领域 Agent 落地最具代表性的案例之一。

**行为规格（Behavior Specs）**：Basis 内部用 Markdown 文件定义 Agent 的行为标准，而非只看最终结果对错。例如，做 tax research 时 Agent 必须引用 IRS 一手来源，即使凭预训练知识能答对，也不被接受——"如果一个人每次都对，但只是因为查的 Wikipedia，那会计事务所不会雇他，我们也不应该。" 这套规格同时充当产品对齐文档和 LLM-as-judge 的评判标准，由会计师与 ML 研究员协作制定。

**Memento 比喻**：LLM 天生有巨大的工作记忆，却没有短期与长期记忆。在长周期任务中，Agent 必须像《记忆碎片》的主角一样，主动为未来的自己留下高信息密度的笔记，才能在数十分钟乃至数天后重建完整状态——这需要一种"对自身的理论思维（theory of mind over oneself）"，而这恰恰是人类不需要刻意训练的能力。

**语境工程 = 运行时训练数据**：他将 context/prompt 重新框架为"运行时训练数据"。设计 Agent 运行环境的本体论（ontology）——数据结构、文件命名、概念定义——与撰写提示词同等重要。代码库本体论的好坏，直接决定了编程 Agent 的上限。

**为什么编程 Agent 最先突破**：可验证性只是部分原因。更关键的是：运行时反馈成本极低（本地直接跑）、训练数据丰富且高质量、工程师社区的"品味"通过大量真实代码隐式编码进了模型。非编程领域三者皆缺，是长周期 Agent 落地的根本难点。

开源项目（与 Braintrust 合作）已发布，包含示例行为规格和判断器，供社区贡献和复用。
