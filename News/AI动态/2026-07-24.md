## PODCASTS

**The MAD Podcast with Matt Turck — The Biggest Chip Ever Built: Why OpenAI Runs On It | Cerebras CEO Andrew Feldman**

**核心观点：AI 推理速度已经成为整个行业最重要的战场，而 GPU 在这件事上存在根本性的架构局限——Cerebras 用一块晶圆大小的芯片重新定义了推理性能的上限。**

Cerebras CEO Andrew Feldman 讲述了一家在"漫长沙漠"中走了十年的深科技公司如何迎来爆发时刻。他们早在 2016 年就押注 AI 推理需要专用芯片，并选择了一条极端路径：把整个晶圆做成一块芯片（wafer-scale），面积是 GPU 的 58 倍，内置内存带宽高出约 2500 倍。

**为什么 GPU 在推理上慢？**

推理的核心瓶颈不在算力，而在内存带宽。每生成一个 token，模型的所有权重（以 70B 参数模型为例，约等于 100 部高清电影的数据量）都需要从内存移动到计算单元，然后重复这个过程。GPU 使用 HBM（高带宽内存），但移动速度仍是瓶颈。Cerebras 选择在超大晶圆内部塞满 SRAM——速度快得多，虽然单位面积存储量有限，但超大尺寸弥补了这个缺陷。

**三个被低估的供应链瓶颈：**

1. HBM 内存全球只有三家厂商（SK Hynix、三星、美光），已严重供不应求——Cerebras 不用这个
2. TSMC 的 CoWoS 封装工艺（主流 GPU 用于多芯片集成）同样排期爆满——Cerebras 不用这个
3. TSMC 的 3nm 工艺产能极度拥挤——Cerebras 用的是 5nm，刚好绕开竞争

**CUDA 护城河正在消失：**

Feldman 直言，两年前业界顶尖模型都在 CUDA 生态里训练，但现在 Gemini 在 TPU 上训练，Anthropic Claude 在 Trainium 上训练，OpenAI 也在摆脱单一依赖。"推理端更没有护城河可言——从 GPU API 切换到我们，只需要改 8 个字符。"

**关于 AI 泡沫：**

他引用了一个经典区分——历史上的泡沫往往是"供给跑在需求前面"（如电信光纤泡沫），而当下 AI 是需求已经在那里，所有人都在追赶供给。"我们被订单淹没，数据中心产能才是瓶颈，这不像泡沫。"

**与 OpenAI 的 750 兆瓦交易**是目前硅谷史上最大规模的交易之一，分 2026、2027、2028 年分批交付，Cerebras 提供完整的云解决方案，OpenAI 通过 API 接入。与此同时，Cerebras 还与 AWS 达成合作，由 AWS 的 Trainium 芯片处理 prefill 步骤，Cerebras 负责 decode 步骤，两者互补形成混合推理架构。

> "你今天用的这个模型，会是你这辈子用过的最差的模型。现在觉得很酷的一切，六个月后就会显得落后和无聊。"
