### Claude Blog

**Claude Code 正式支持 Artifacts 功能**

Claude Code 推出 Artifacts 功能（目前面向 Team 和 Enterprise 用户开放 beta）：将 Claude Code 的工作成果转化为实时可分享的可视化页面，包括 PR 演练说明、系统架构文档、可过滤排序的仪表板、自动勾选的发布检查清单等，并随 session 进展自动刷新更新。

Artifacts 基于当前 session 的完整上下文构建，涵盖代码库、连接器和对话本身，无需另行搭建数据管道或基础设施。每次发布都会在同一链接更新并保留版本历史，团队成员始终看到最新状态。Artifacts 默认对创作者私有，仅限组织内已认证成员查看，管理员可通过合规 API 进行访问控制和保留策略配置。

内部测试中最常见的用例是 incident 调查：工程师在站会前发起调查，Claude Code 持续发布并更新 artifact，到站会开始时，团队成员无需"听汇报"，直接查看同一份实时更新的文档。

https://claude.com/blog/artifacts-in-claude-code

### The MAD Podcast with Matt Turck

**The Neocloud Boom: State of AI Compute 2026 | Stephen Balaban**

**核心观点**：GPU 算力从来就不是商品，而是高度垂直整合的云服务——那些预测 Neocloud 会被商品化的人，从一开始就判断错了。

Lambda 联合创始人兼 CTO Stephen Balaban 从物理层拆解了 AI 算力的完整链条：土地许可、数据中心建设、高性能计算设计，再到云软件和虚拟化。他的核心判断是：我们整体上依然处于"算力不足"（underbuilding）的状态，Scaling Laws 尚未见顶，模型能力的提升将持续扩大 AI 的可寻址市场。

关于"算力效率提升 10 倍会怎样"的担忧，Balaban 给出了反直觉的回答："效率提升 10 倍的结果，只会是每个人处理 10 倍的 token，世界上可用算力总量不变，需求同样无穷无尽。"

他还分享了一个关于 GPU 资产价值的洞察：2023 年部署的 H100，今天的租赁价格反而高于当年购入时——这正在让信贷市场开始将 GPU 视为成熟资产类别，专项融资结构（SPV、基于资产的贷款）因此日益活跃。

Lambda 的起源故事同样曲折：2012 年从人脸识别 API 起家，做过内嵌摄像头的棒球帽（Lambda Hat）、早期版 Midjourney 式的 Dreamscope 图像滤镜；为了把 4 万美元/月的 AWS 账单降到零，咬牙花 6 万美元自建 GPU 集群，意外发现了云计算商业模式，如今年收入接近 10 亿美元，已完全退出硬件销售业务。

谈到 AI 的未来，Balaban 提出"Neural Software"（神经软件）概念：LLM 不只是生成代码，而是本身就成为软件——所有交互都在神经网络的特征激活空间中完成，不存在静态代码运行。他预计大规模普及需要 10-15 年，并类比苹果"一人一台电脑"的愿景：从 1976 年提出到 2014 年真正实现，花了近 40 年。Lambda 正在朝"一人一 GPU"的未来推进，但这是一个代际目标。

> "我们现在已经有了一个神奇的系统——它能吃进钱，吐出软件。那些说'五年后你们就会把 GPU 扔掉'的人，从头到尾都错了。"
