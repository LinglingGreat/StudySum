## 官方博客

**Claude Blog — Claude Code 现已支持 Artifacts**
https://claude.com/blog/artifacts-in-claude-code

Claude Code 推出 Artifacts 功能，可将会话工作进度转化为实时共享的可视化页面，包括 PR 演练、系统架构图、仪表盘和发布清单，并随会话推进自动更新。

核心机制：Artifacts 基于完整会话上下文构建，能将代码库数据、外部连接器数据（如监控工具告警）和 LLM 推理结论整合到同一个页面。每次发布生成新版本，URL 不变，支持版本回溯。

权限设计：默认仅作者可见，可手动分享给团队或全组织；不能设为公开；管理员可通过合规 API 获取全组织可见性。

典型场景：工程师在站会前开始排查故障，Claude Code 工作过程中实时发布进展页面，团队成员打开同一链接即可看到最新调查结论，无需口头同步。

当前阶段：Beta，仅对 Team 和 Enterprise 版本开放，支持 CLI 和桌面应用，页面可在任意浏览器查看。

## 播客

**Unsupervised Learning — Ep 92: xAI Co-Founder Unpacks the Future of Model Development**
https://www.youtube.com/@RedpointAI

**核心观点：** 闭源模型提供商正被开源模型和监管双重夹击，而下一个大机会在于真正个性化的本地 AI。

Igor Babushkin 曾在 DeepMind 主导 StarCraft AI 和 AlphaCode，在 OpenAI 参与早期推理研究，后成为 xAI 联合创始人，主导 Colossus 超算集群建设。他最近离开 xAI，创立 River AI，专注三个方向：企业级 fine-tuning 服务（River API）、真正个性化的个人 AI agent、以及本地推理硬件。

他对行业格局的判断颇为直白：**"闭源模型提供商现在处于两难境地——模型做得太强，可能被禁止发布；但开源模型每个月都在追赶。"** 他认为 OpenAI 和 Anthropic 的出路只有一个：继续创新，探索新域，而非维持现有商业模式。

**个性化 AI：** 现有模型是为"平均用户"训练的，River 的赌注是：真正的个人 AI 应该像 TikTok 推荐系统一样，端到端学习每个人的偏好、节奏、审美，以最大化个体满足感为优化目标。"这种推荐系统与 agent 的结合，从来没有人真正做过。"

**本地硬件：** Igor 相信本地推理设备（放在家里或办公室的小盒子）能提供更低延迟、更强隐私保护，并让用户真正拥有自己的模型，而不是依赖他人 API 的访问权限。这也是个人 AI 能获取深度隐私数据（文件、对话、行程）而不令人担忧的前提。

**开源模型与地缘政治：** 他既认可中国开源模型对生态的贡献，也指出潜在风险：依赖中国实验室意味着授权条款随时可能改变。他明确呼吁美国应拥有全球最强的开源模型，而不仅仅是"最强的美国开源模型"。

**AI 安全：** 减速在现实中难以实现，但应当加速对齐技术研究，让更多研究者能接触接近"危险阈值"的开放模型，广泛测试对齐方法，而不是将这些思考局限在少数几家大型 AI 实验室内部。
