**Training Data — Parallel's Parag Agrawal: Building a New Web for AI Agents**

**一句话总结：** 前 Twitter CEO Parag Agrawal 认为，人类点击数据是搜索系统的"bug"，为 agent 构建的搜索引擎必须从零重构——新的索引架构、新的排序信号、新的商业模式。

Parag Agrawal 创立 Parallel Web Systems 的核心判断是：agent 使用搜索的频率将是人类的 1000 倍，而现有搜索引擎在架构、反馈信号和商业逻辑上根本不适合服务 agent。

**最反直觉的洞见** 是：人类点击数据本质上是「为懒人优化」的副产品。人类的惰性催生了海量 SEO 内容，而 agent 不懒、不打错字、查询描述更精准——这让搜索引擎得以跳过整套针对人类的优化链条，直接从最权威的来源抓取最相关的段落。

在延迟优化上，Parallel 将搜索响应时间从数秒压缩至 200 毫秒内（其 TurboNow 产品）。实际效果是：「如果你用 Parallel Search，agent 消耗的 token 不到原来的一半，结果更准，速度更快。」

**商业模式** 上，Parallel 的方案是 **Shapley Value（夏普利值）**：通过模拟「如果没有这个内容源，agent 输出质量会下降多少」来计算内容的边际贡献，向内容提供方支付差异化报酬。高价值内容、高价值工作场景双重溢价。Parag 估算，若将 AI 推理支出的 2-10% 分配给网络内容，将远超今天所有网络内容商业模式的总和。

**最新进展：** Parallel 宣布与 Google Cloud 合作，成为 GCP 企业 agent API 的搜索和 grounding 提供商——用户在 GCP 上使用 Gemini 模型时，可选择 Parallel Search 作为网络搜索后端。
