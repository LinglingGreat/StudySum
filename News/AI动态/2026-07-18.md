### Anthropic Engineering

**An update on recent Claude Code quality reports**

Anthropic 复盘了近期 Claude Code 质量下滑的三个独立 bug，均已修复：

1. **默认推理强度降级**（3 月 4 日）：为解决高延迟问题，默认 reasoning effort 从 high 调为 medium，导致智能水平肉眼可见地下降。4 月 7 日回滚，Opus 4.7 现默认 xhigh，其他模型默认 high。

2. **缓存优化 bug 导致推理历史持续丢失**（3 月 26 日）：设计上是"idle 超过 1 小时就清一次旧 thinking block"，bug 导致此后每轮都清，Claude 上下文记忆不断被截断，表现为遗忘、重复、奇怪的工具调用。4 月 10 日修复。

3. **系统 prompt 字数限制伤害编码质量**（4 月 16 日）：为降低 Opus 4.7 的冗长倾向加了一条强限字数的 prompt，配合其他 prompt 变化后对编码质量产生了明显负面影响，4 月 20 日回滚。

三个 bug 影响的流量各不相同、时间段错开，叠加呈现出广泛且不一致的劣化，增加了排查难度。目前已全部修复，并为所有订阅者重置了使用限额。
https://www.anthropic.com/engineering/april-23-postmortem

**Scaling Managed Agents: Decoupling the brain from the hands**

Anthropic 工程团队分享了 Managed Agents 的架构设计：将 agent 的"大脑"（Claude + harness）、"双手"（sandbox/工具执行环境）和"session"（事件日志）彻底解耦，每个都是独立接口，任何一个宕机不影响其他组件。

核心收益：任何组件失败都可以独立恢复；credentials 永远不进 sandbox，安全边界更清晰；harness 从 container 里移出后，不需要工具的 session 无需等容器启动，p50 首 token 延迟下降约 60%，p95 下降超 90%；每个大脑可连接多个手，每个手也可以被多个大脑共享。

借鉴操作系统虚拟化硬件的设计哲学：抽象层稳定，底层实现随时可以替换。
https://www.anthropic.com/engineering/managed-agents

### Claude Blog

**New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels**

Claude Managed Agents 推出两项新能力：

**Self-hosted sandboxes**：agent 的工具执行环境现在可以运行在你自己的基础设施或合作托管商（Cloudflare、Daytona、Modal、Vercel）上。代码执行、敏感文件、私有服务全部留在企业边界内，Anthropic 侧只负责 orchestration。

**MCP tunnels**：可以将 Managed Agents 连接到私网内的 MCP 服务器，无需公网暴露。私有数据库、内部 API、知识库都能成为 agent 可调用的工具。轻量 gateway 只需发起一条出站连接，流量全程加密。

目前 self-hosted sandboxes 公开 beta，MCP tunnels 为 research preview。
https://claude.com/blog/claude-managed-agents-updates

## PODCASTS

**The MAD Podcast with Matt Turck: OpenAI's Compute Chief: We Can't Build Fast Enough | Sachin Katti**

**核心洞察**：对 OpenAI 来说，算力从来没有"够了"这个状态，每次以为可以踩刹车，现实都会打脸。

Sachin Katti 是 OpenAI 工业计算负责人，此前是 Stanford CS/EE 教授、多次创业者、Intel CTO。他的职责覆盖算力上线的全生命周期：找地、拉电、建机房、采购芯片、融资、内部容量分配。

几个值得关注的观点：

**需求端没有天花板**：OpenAI 今年算力支出约 500 亿美元，全行业约 7000 亿。AI 开始做 AI 研究之后，可运行的实验数量爆炸式增长，过去受限于人类研究员数量的瓶颈消失了，所需算力随之膨胀。"我们从来没有觉得算力够过。每次以为可以放慢，现实总会给我们一巴掌。"

**数据中心 = "把电子变成 token 的巨型工厂"**：液冷已是标配，因为芯片温度极高，风冷不够用。散热能力越强 → 芯片跑得越热 → 更多 memory bandwidth 和 FLOPS → 更多智能产出，直接影响经济性。

**Jalapeno 芯片**：OpenAI 自研推理 ASIC，9 个月从设计到流片（极快）。核心优势是"知道自己要跑什么模型"，可以联合设计硬件，最大化 tokens per watt。AI 本身也参与了芯片设计，大幅加速迭代。"AI 用 AI 设计它自己需要的芯片，这个递归循环已经不远了。"

**MRC 网络协议**：为 10 万 GPU 级别集群设计的多路径 spraying 协议，任意两块芯片之间存在多条路由，某条链路故障不影响整体训练任务，核心是可靠性和可用性。

**能源**：核能"来得越快越好"，是最密集、最清洁的能源形式。目前数据中心建设的真正瓶颈反而在物理供应链 — 燃气轮机、变压器产能多年来几乎没有扩充，突然面对需求冲击；电工、水管工等技工严重短缺。
