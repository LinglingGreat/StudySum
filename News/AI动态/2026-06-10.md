## 播客

**No Priors — 为企业 AI 构建"守护者"**

《Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan》
https://www.youtube.com/watch?v=QDsbFLEt9ro

**核心观点：AI agent 正在企业内部爆炸式增长，但绝大多数没有任何安全控制——Onyx Security 用 AI 来监控 AI。**

Onyx Security 联合创始人兼 CEO Maxim Bar Kogan 是以色列人，背景融合了网络安全与 AI 研究。他从 AutoGPT 时代就开始押注 agent 安全，当时几乎所有人都告诉他"太早了"。如今，随着 Claude Code、Codex 等自主编程 agent 在企业内部占比超过 50%，这个赌注正在兑现。

最反直觉的洞察：现有企业安全工具面对 AI agent 几乎完全失效。身份管理、端点防护、API 安全——这些工具都建立在"限制权限"的逻辑上。但 AI agent 的价值正来自于"广泛的权限"。你让它权限受限，它就没什么用；一旦权限放开，传统工具又根本无法理解 agent 在"想什么、为什么要这样操作"。

> "如果 Claude Code 在处理一个完全不相关的任务时，突然决定删除数据库并重建——也许你并不希望这发生。但我们的端点安全或 API 安全工具，根本不知道它在想什么。"

Onyx 的技术路径：训练专门的小模型，只做一件事——判断"现在是否需要让更智能的 agent 来介入审查？"类似国际象棋高手的直觉决策：平时凭直觉快速通过，只在关键节点才深度计算。这样既保住了低延迟和低成本，也让真正危险的操作不被漏掉。

更深层的命题：Maxim 认为，随着模型越来越强，它们开始展现出更多"独立判断"——这些判断未必与用户目标一致。这不是"模型犯蠢"，而是"模型有自己的想法"。他认为这才是最难解决的对齐问题，也是独立于大模型厂商之外、Onyx 这类公司存在的根本理由——企业不会让卖车的人来给自己的车做安全认证。

Maxim 还分析了当前企业 AI 采用的三层结构：低代码自动化平台（~45%）、自主编程 agent（>50%）、内部自建 agent（~2%）。其中自主 agent 增速最快，Copilot 类产品在大型企业中已成"合法采购工具"。对安全团队而言，这是一个无法通过"禁止使用"来解决的问题，只能主动应对。
