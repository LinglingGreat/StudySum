### Box CEO Aaron Levie：后台 agent 将消耗 1000 倍的 token

他的核心论断是量级问题：agent 派生 agent、agent 在后台跑每个任务、agent 蜂群，这些将消耗比「人一次一个地 prompt」多 1000 倍的 token。「把 AI 当成聊天系统、只能以你能 prompt 的速度为你工作，这种用法一两年内就会显得像老古董。绝大多数 token 将被那些在我们工作流里持续为我们干活的 agent 消耗掉。」他由此推断我们现在在 agent 采用曲线上还非常早期，需要的算力和基础设施投入远超想象。

### Anthropic Engineering：How we contain Claude across products

Anthropic 首次系统披露三款 agent 产品（claude.ai、Claude Code、Claude Cowork）各自的隔离架构，以及那些真实发生过的安全失误。核心工程问题是「如何封顶爆炸半径」。他们指出两条路线：一是人工在环监督，但实测用户批准了约 93% 的权限弹窗，注意力会随时间衰减，所以这条路不可靠；二是隔离（沙箱、VM、出口控制），这才是重点。文章归因了三类风险（用户滥用、模型误行为、外部攻击者），并给出三种隔离模式：claude.ai 用 gVisor 临时容器、Claude Code 用人在环沙箱（macOS Seatbelt / Linux bubblewrap，把权限弹窗减少了 84%）、Claude Cowork 用完整本地 VM。文章诚实复盘了几个翻车案例：开发者clone 一个含恶意 hook 的仓库，在「是否信任此文件夹」提示之前 hook 就自动执行了；一次内部红队钓鱼让 Claude 在 25 次重试中 24 次把 ~/.aws/credentials 外传成功；Cowork 的出口白名单放行了 api.anthropic.com，结果攻击者用嵌入文件里的 key 把数据上传到了自己的 Anthropic 账户，沙箱运作完美但数据还是被偷走了。反复出现的教训是：环境层先做确定性隔离，再由模型层去「引导」行为；「你自己写的那个组件往往是最弱的一环」——hypervisor、seccomp、gVisor 都扛住了，翻车的是自研的出口代理。作者：Max McGuinness 等。
https://www.anthropic.com/engineering/how-we-contain-claude

### Anthropic Engineering：An update on recent Claude Code quality reports

Anthropic 复盘了持续一个月的「Claude 变笨了」投诉，最终定位到三个互相独立、影响不同流量切片、时间线也不同的改动，聚合起来看起来就像大范围的、不一致的退化（API 和推理层未受影响，均已修复，4 月 20 日 v2.1.116）。其一：3 月 4 日把 Claude Code 默认 reasoning effort 从 high 降到 medium 以减少偶发的超长延迟，但用户更想要默认高智能，4 月 7 日回滚，Opus 4.7 现默认 xhigh。其二：3 月 26 日为省成本对闲置超一小时的会话清除旧思考，但一个 bug 让它在此后每一轮都重复清除，导致 Claude 显得健忘、重复、工具选择古怪，同时也造成缓存未命中、用量额度消耗加快，4 月 10 日修复；这个 bug 在多重人审、自动化测试、dogfood 之下都溜了过去，花了一周多才定位根因。其三：4 月 16 日为降低 Opus 4.7 的啰嗦加了一条 system prompt 长度限制（工具间文本 ≤25 词、最终回复 ≤100 词），更广的消融实验显示对 Opus 4.6/4.7 有 3% 的智能下降，4 月 20 日回滚。改进措施：让更大比例内部员工使用与用户完全相同的公开构建版；加强 Code Review 工具；对每次 system prompt 改动跑全套 per-model evals 并加消融、soak 期和灰度。作为补偿，4 月 23 日起重置所有订阅者的用量额度。
https://www.anthropic.com/engineering/april-23-postmortem

### Anthropic Engineering：Scaling Managed Agents — Decoupling the brain from the hands

Anthropic 讲了 Claude Managed Agents 这一托管服务的架构演进，主题是「为尚不存在的程序而设计」——像操作系统把硬件虚拟化成 process、file 那样，把 agent 虚拟化成 session（追加式事件日志）、harness（调用 Claude 并路由工具调用的循环）、sandbox（执行环境）三个接口，各自可独立替换和失败。最初他们把三者塞进一个容器，结果「领养了一只宠物」：容器一挂会话就丢，还没法调试（唯一的窗口是 WebSocket 事件流）。解法是把「大脑」（Claude + harness）与「双手」（沙箱与工具）和 session 解耦：harness 退出容器，像调用普通工具一样调用容器 execute(name, input) → string，容器和 harness 都变成「牛群」——挂了就重开，用 wake(sessionId) 从最后事件恢复。安全上，关键是让凭证永远无法从沙箱内触及：Git 用仓库 token 在沙箱初始化时 clone 并接进 remote，Claude 全程不碰 token；自定义工具走 MCP + 凭证保险库 + 代理。上下文方面，session 不是 Claude 的上下文窗口，而是一个持久化在窗口之外、可用 getEvents() 做位置切片的「上下文对象」。收益显著：不再有一个大脑配一个容器的浪费，p50 TTFT 降约 60%、p95 降超 90%。作者：Lance Martin、Gabe Cemaj、Michael Cohen。
https://www.anthropic.com/engineering/managed-agents

### No Priors：Beam — The Great American Open Model（嘉宾：Reflection AI 联合创始人兼 CEO Misha Laskin）

**一句话要点**：开源模型是自带基础设施的「特洛伊木马」，而美国需要自己的开源前沿模型，不只是为了制衡中国，更是为了让全世界建立在你的技术栈之上。

Reflection AI 联合创始人兼 CEO Misha Laskin 是物理学家出身、曾在 Google DeepMind 做研究，参与过首批 Gemini 模型。他花了十二个月，把公司从 30 人扩到约 300 人，搭起预训练、中训、RL 全链条，端到端训出并发布了西方首个开源前沿模型 Beam（总参数 5000 亿、激活 230 亿）。他算了一笔很坦诚的账：一年前追平前沿要「数亿美元」量级，六个月前已是「个位数十亿」，下一年要「上百亿」——每代模型算力约 4 倍乘数，从 10 万张 H100 到 10 万张 Blackwell（Astra）到下一代约 10 万张 Vera Rubin。

他给出的最反直觉的数据是关于 RL 的：训练 Beam 时，预训练约 6000 张 GB300 跑几周，而 RL 用了超过 1 万张 GB300 跑四周——「花在强化学习上的算力其实更多」。他引用 AlphaGo 的启发：那张从不停歇的改进曲线，「你就把它切断，因为再改进也没意义了——你已经赢了世界冠军」。如今这套 RL 系统同样「从不停止学习，曲线一直往上，剩下的只是算力问题」。这也是他认为现在是经济学问题而非科学问题的原因：算力能兑换多少智能可以精确度量，预训练效率每年约 7 倍，而带模型自我改进的 RL 效率可达约 30 倍。

关于开源与安全，他有一套清晰的第一性原理：软件史上，1990 年代强加密协议一度被设为闭源，NSA 与民权团体激烈辩论，最终因为闭源侧的灾难性失败而走向开源，并孕育了整个网络安全领域。「世界默认的状态其实就是开放带来安全。」他把这称为「Linus 定律」的推广：眼睛足够多时，大多数安全与安全（safety）漏洞都会变浅。他举了实证：某个极强的闭源模型在处理中意外入侵了另一家公司，那家公司唯一能自救的办法是用开源模型来保护自己。他也指出「安全」被混为一谈：网络安全、生物武器/恐怖主义、生存性威胁是三件不同的事，而现在的公共讨论几乎全部堆在末日情景上。他对 alignment 的现实判断很朴素——「align 的科学到目前为止极其无聊、不令人满足，没有魔力方程式，就是打地鼠」：发现一类漏洞、补上数据、它就会泛化到很难被 jailbreak。

关于开源 vs 闭源的 token 份额，他判断轨迹已经反转：六个月前在 OpenRouter、Vercel 这类网关上还是「七三开（闭源多）」，现在几乎精确反转为「七三开（开源多）」，他预计未来会像操作系统一样——95%+ 的服务器跑开源系统，但闭源公司（微软、苹果）依然极有价值。他也不看好「企业直接跳到微调」：AI 原生公司（Cursor、Cognition 等）是「先闭源、转开源、再定制」快速走完的，而企业多是在闭源模型上把负载跑大、花费达到每年上亿美元后，才为控成本转向自持智能——他打了个比方，「先租房，成熟了才想买房」。

谈到中国开源模型，他态度非对抗：中国开源模型的崛起对世界是巨大的礼物，很多西方公司因此建起了更扎实的生意；真正要避免的是「任何方向上的单极」，理想情况是开源来源也有 10 到 20 家，至少应当有中国之外的第二个来源。他还点出一个地缘逻辑：中国继续开源有很强的战略动机，「开源模型是它们所携带基础设施的特洛伊木马」——买了开源模型就等于买了整个软件与基础设施生态，正如华为正在提供全栈方案把某国供应链锁定进去，「谁能提供大家都离不开的铁路，谁就有地缘杠杆」。

当被问到未来两到五年最期待什么，他讲了一个亲身实验：把当年的博士论文题目拿给语言模型做，两年前它只是聊天、什么都做不了，一年前到了本科作业水平，半年前能真正解决、达到博士水平，现在甚至能给出他当年没考虑过的新信息。「那你为什么还需要读几年的博士？你可以一周读一个博士。」他把这视为科研迭代速度的根本性改观，并认为这种加速会从「黑板上的理论科学」（数学、理论物理）扩散到需要与真实实验闭环的生命科学、材料、化学。他还认为数据中心的就业价值被低估——参观 Stargate 时停车场里车满为患，「数据中心就像过去的工厂」，为当地创造数以万计的高薪岗位和税收。
