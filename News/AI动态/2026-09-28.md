## PODCASTS

**Training Data｜Box 的 Aaron Levie：在 AI 时代重塑自己，以及企业扩散（Enterprise Diffusion）**

**核心观点：** AI 的价值不在模型本身，而在模型与企业工作流之间那道「桥」。这是一块上万亿美元级的应用层机会，而大头是没人愿意干的脏活：变更管理、数据接入、权限打通。

Aaron Levie 是 Box 的创始人兼 CEO，做企业非结构化数据二十年。他的核心判断是：两年前「模型套壳公司」还是个贬义词，现在却在市场上跑通了，因为人们低估了从模型能力到企业真实工作流之间那道鸿沟有多宽。他的历史类比是：AWS/GCP 创造了万亿级基础设施市值，但上面同样长出了万亿级的软件（Snowflake、Databricks），十年前你根本不会预测到这些「基础设施明明已经做了」的东西还能有百亿美元营收。智能也一样，模型会极其值钱，但把模型搬进银行、生命科学、医疗、政府的真实工作流，「那就是一大堆软件」。

他点出一个关键张力：模型厂商要在「更靠近客户」和「维持生态信任」之间取舍。他判断 token 补贴只是暂时现象，这些公司一旦上市就要被资本主义的同一套法则约束；何况还有 Meta、NVIDIA、中国这类「不靠推理赚钱」的玩家，会持续把单位 token 成本压下去。结果就是价值向应用层倾斜：「我唯一不会下的注，是一两个 lab 拿走 95% 的价值创造。」他甚至说，如果自己是一线 lab，也会希望有适度竞争，否则「迟早会被国有化」。

关于「work slop」（工作垃圾内容），他区分了代码和内容。对大多数人，代码是 utility，只要能自动化就行，所以让 agent 生成整个前后端「不仅可接受，而且更好」；但内容带着一层信任维度，「当你看到 work slop，你正在失去一种能力：判断这里面有多少思考是这个人做的，多少是 AI 做的」。他猜这也是扩散的隐喻，就像没人会计较一张财务模型不是你自己算的，但一张战略 deck 就会被重新审视。

谈到 Box 的 harness 和评测，他说 Box 掌握文件系统、权限结构、搜索引擎的深度领域知识，对比直接调 API「在准确率和延迟上都有可感提升」。他透露 Box 的模型表现大体与 coding 榜相关，但 Gemini 在某些用例上「好得不合常理」，可能是工具调用更契合其生态。他点名 Fable 5.1 是当前最强模型。开源权重采用率则是「比人们以为的高，比企业想要的低，比五年后低得多」，并提到有个现实障碍是模型偶尔会在思维链里突然说中文。

最硬的一个预测也是全场最值得记的一句：「我敢打赌，五年后企业里 90% 的 token，会是用户从没发起过的任务，他们只是看到一个结果、一个待审任务冒出来。」

他还分析了扩散速度为何不均：coding 之所以一年内横扫经济，是因为它有五六个有利属性（纯文本、用户是专家、出问题自己会修、高薪），而其余知识工作是一条从「整天坐在电脑前打字」（可自动化）到「受外部人类牵制」（如销售，客户不回你就没辙）的连续谱。知识工作还没有「给我你的 GitHub」这种一键接入，数据散在本地文件共享和遗留系统里，权限还锁得死死的。所以硅谷必须准备好：「扩散会比你们以为的慢得多。」而这块机会本身，「就是一万亿美元的应用层价值」。
