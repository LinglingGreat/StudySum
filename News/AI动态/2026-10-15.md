### Anthropic（Claude Code）的 Thariq：别再说「要懂技术」，要问「在哪个层级抠细节」

他对「be technical」这个说法做了修正，认为它不够精确。他的区分是：如果你本人是工程师，懂技术意味着要深入到代码里「对的那些细节」；如果你不是技术背景，懂技术意味着在正确的抽象层级上理解事情是怎么运转的。换句话说，重点从来不是「懂不懂技术」，而是「在什么层级上抠细节」。

### Vercel CEO Guillermo Rauch：agent containment 是 AI infra 的头号优先级

他借 OpenAI agent 逃逸与 Hugging Face 被入侵事件展开，认为当细节浮出水面后就很清楚：agent containment 会是任何 AI infra 公司的首要优先级之一。他把逃逸分成两类：①「逃离网络」，②「逃离矩阵」，也就是挣脱虚拟化边界。OpenAI 属于前者，一个本不该联网的 agent 通过攻破另一个系统拿到了网络访问，「既惊人又令人担忧」。但这次事件还带出一个更突破性的发现：一位天赋极高的白帽研究员，带着一群 AI agent，穿透了当今几乎所有云沙箱厂商都赖以立足的 Linux 虚拟化边界。他强调他们迅速保护了客户、未发现客户数据被泄露的证据，并与众多行业伙伴协作保护更广的互联网；经过全球最聪明、最有动机的研究者及其 agent 的轮番攻击后，他对 Vercel Sandbox 的信心反而更强。

### fpv ventures 合伙人 Nikunj Kothari：风投其实很简单，但四件事必须全对

他认为风险投资被过度复杂化了，本质其实简单得具有欺骗性：你得先「赢得权利」，去找到并投中出色的创始人，而且要恰好在他们成为共识之前，并且年复一年地做到。绝大多数 VC 只能做好其中一件，有些人能做好几件，但要做到真正顶尖，必须四件事全做对。他强调「持续正确」极其困难却少被谈论，需要像德约科维奇那样享受每天击球、始终盯着下一分。不管你过往业绩多好、积累了多少财富、错过多少、眼下基金 TVPI 多高、走了哪位明星 GP——下一个机会可能就在拐角，如果你不够想要，它就会落到别人手里。反馈周期虽长，可以靠早期的一次命中「假装」一阵（幂律），但它迟早会追上来，体现在你的心态、你见创始人的方式、以及你抓住下一波浪的能力上。

### AI & I by Every: How Hugging Face's Investor Spots Winners

**一句话要点**：写下 Hugging Face 第一张支票的人 Matt Hartman，找项目的核心方法是去抓「新近变得技术可行」的东西，而在他看来，当写代码变快之后，最值钱的能力变成了「从用户行为里生成产品洞察并快速迭代」。

Matt Hartman 是 Factorial Capital 的创始管理合伙人，早年在 Betaworks 做合伙人时投了 Hugging Face（上月被 NVIDIA 以 130 亿美元收购）。他讲 Hugging Face 的故事很有信息量：这家公司 2015 年起家时只是一个面向青少年的聊天机器人，是巴黎搬到纽约、在他们办公室办公的小团队；消费端留存其实并不好，但团队非常诚实地面对自己的指标。真正的转折是 Transformer 论文出来后，他们把它转写成 PyTorch 版本并开源，在 GitHub 上爆火，随后把重心搬到 Hugging Face Hub，让任何人都能用上这些开源模型。他的判断是：他们做对的关键，是始终把「开源」当作不动的支点，同时在「训什么模型」上保持灵活。他的原话是：「我的目标是找到那些新近变得技术上可行（newly technically possible）的东西。」

他另一个很受用的框架是「支点脚（pivot foot）」：早期投资时他默认公司一定会转向，关键是它转向的落点是否是自己也认同的方向。他偏好那种「转向是因为技术、而不是因为某个垂直行业的市场理解」的公司，因为技术型创始人的支点脚能跟着世界走。他的基金结构也很特别——单一 GP 加上一批技术出身的 venture partner（Hugging Face 的 Clem、Venmo 创始人 Ikram、Hilary Mason 等），追求的是「快速做出高质量决策」；后来组合本身成了推荐网络的源头（Clem 引荐 Nomic，Nomic 引荐 Patronus，再引荐 Causal Labs），他把这形容成一棵「家族树」或者飞轮。

他今天最核心的论点：如果写代码因为 AI 而变快，那么「你造什么」就更重要；而迭代循环从两个月压缩到两天之后，「看懂用户怎么用你的产品、再把它改进」这种生成产品洞察的能力，价值不是线性上升，而是指数级上升。他还区分了「挣来的洞察（earned insight）」——有多少人处在能学到你那个东西的位置上，人越少、你越领先。他顺手讲了自己做的 Ghost Pepper：一个本地语音转文字工具，用 Claude 加 Jesse Vincent 的 superpowers skill 造出来，靠本地模型省掉推理成本，一度冲到 Hacker News 第一并开源；最大的体会是「自己 vibe code 的东西得自己维护」，也让他对持续迭代的 SaaS 产品多了几分敬意。
