### Anthropic Engineering

**Claude Code 质量下降事件复盘**

Anthropic 详细披露了近期 Claude Code 质量下降背后的三个独立问题。

第一，3 月初将默认推理强度从 high 降为 medium（理由是减少延迟），此举被证明是错误的权衡，4 月 7 日已恢复；目前 Opus 4.7 默认为 xhigh，其余模型为 high。

第二，3 月 26 日上线的一项缓存优化存在 bug：会话超过 1 小时闲置后，每一轮都会清除思维历史而非只清除一次，导致 Claude 表现得健忘且重复，同时引发缓存未命中、用量消耗异常加速。4 月 10 日已修复。事后用 Opus 4.7 对相关 PR 做 Code Review，找到了这个 bug；Opus 4.6 没找到。

第三，4 月 16 日为压缩 Opus 4.7 冗余输出加入的 system prompt 指令（"每次工具调用间不超过 25 字，最终回复不超过 100 字"）损害了代码质量，4 月 20 日已回滚。

三个变更波及不同时段、不同流量，叠加后呈现出看似全面的能力下滑，排查困难。作为补偿，Anthropic 于 4 月 23 日重置了所有订阅者的用量限额。后续将收紧 system prompt 变更的管控流程，每次改动都要跑完整 eval 套件，并做灰度发布。

**Managed Agents 架构解析：将"大脑"与"双手"解耦**

Anthropic 工程博客介绍了 Managed Agents 的底层架构设计。核心是将 agent 拆成三个独立接口：**session**（事件日志）、**harness**（调用 Claude 并路由工具调用的主循环）、**sandbox**（执行环境），三者可独立替换或故障，互不拖累。

主要改进：

- **Harness 移出 container**：container 成为"牲口"而非"宠物"，挂掉直接换新，无需人工介入。
- **凭据与 sandbox 彻底隔离**：生成代码的执行环境接触不到任何 credentials，从结构上堵住 prompt injection 导致的凭据泄露。
- **Session 独立于上下文窗口**：long-horizon 任务可通过 `getEvents()` 按需取回历史事件，支持灵活的 context engineering。
- **性能提升显著**：架构调整后，p50 首 token 延迟（TTFT）降低约 60%，p95 降低超 90%。

文章以操作系统抽象硬件的思路类比 Managed Agents 对 agent 组件的抽象，核心设计哲学是"为尚未出现的程序设计系统"，接口保持稳定，实现随时可换。

https://www.anthropic.com/engineering/managed-agents

### Claude Blog

**Managed Agents 新功能：自托管沙箱与 MCP 隧道**

Claude Managed Agents 现支持企业在自有基础设施（或 Cloudflare、Daytona、Modal、Vercel 等托管服务商）上运行工具执行环节，敏感文件和服务无需离开企业内网，网络策略、审计日志、安全工具均在企业侧掌控。

同期推出 **MCP tunnels**：agent 可连接私网内部的 MCP 服务器（内部数据库、私有 API、知识库等），无需对外暴露端口，流量端到端加密，仅需在企业侧部署一个轻量网关做单向出站连接。

- 自托管沙箱：public beta
- MCP tunnels：research preview（需申请）

https://claude.com/blog/claude-managed-agents-updates

Claude 的 connector 目录新增 AllTrails、Audible、Booking.com、Instacart、Spotify、Uber、Uber Eats、Tripadvisor 等 15 款消费类应用，现有 connector 总数已超 200 个。

### AI & I by Every

**《我们用 AI 自动化了一切，员工却增加了三倍》**

> "只要你跟上模型的进化，你就没问题。"

Every COO Brandon 与 CEO Dan Shipper 围绕 Dan 的长文《After Automation》展开对谈，核心论点反直觉：越多自动化，反而催生越多人类工作。

**为什么？** AI 把"昨日的专家能力"变得廉价，人人都能生产大量"差不多但不够好"的代码、文章和设计。这种同质化的低质供给反而推高了专家需求，因为要有人来鉴别、过滤、修正，并搭建让这些 AI 输出真正可用的系统。Every 从 GPT-3 时代的 4 人团队扩张到如今 30 人，正是这一逻辑的现实注脚。

Dan 的另一个关键洞察：agent 和人类之间的根本区别不是能力强弱，而是**主体性**。无论 agent 多强，它始终在等你告诉它"什么重要"。连 AGI 出现之后，这一点恐怕也不会消失，因为整个行业的激励结构指向更加顺从的 AI，而非自主行动的 AI。

对于 ClickUp 大裁员并将其归因于 AI 的做法，Dan 直接表示怀疑，认为更可能的原因是公司业绩不佳加上管理臃肿，AI 只是一块遮羞布。他也提到，Jensen Huang 的说法有道理：如果 AI 浪潮下你的答案是裁员，说明你缺乏创造力。
