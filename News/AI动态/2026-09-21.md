对个人 agent 赛道做了一份全景判断，核心观点如下：

**Muse 有望成为领头羊。** Meta 在自家所有平台积极推广，app 体验直觉流畅。他认为一个独立 app 比把 agent 塞进 iMessage 更合理，预测这将是 Meta 继 Facebook 之后最成功的自研 app，规模远超 Threads。

**ChatGPT 目前仍是实际领导者**，因为已有 10 亿以上用户，且模型能力和 voice/computer use 功能整体领先。但他指出，同时服务工作和个人场景、兼顾企业和消费者 UX 是两难困境——他自己已开始用 Grok Bot 处理工作，因为 Work/Codex 分拆逻辑太让人困惑。

**最大的未解难题是多人协作。** Muse 没法轻松拉伴侣进来一起规划旅行，ChatGPT 和 Grok Bot 也无法方便地让同事加入线程。他预计这将是下一个重要突破点。

他建议用户把个人技能和文件设计成可跨 agent 迁移的格式，否则会把一半时间花在切换工具上。

### No Priors —— Coinbase CEO Brian Armstrong：Agentic Finance、稳定币与代币化

**一句话要点：** AI agent 需要自己的银行账户，而加密轨道是让这件事成为可能的最短路径。

Brian Armstrong 是 Coinbase 联合创始人兼 CEO，同时也是抗衰老公司 New Limit 的联合创始人，是少数同时在加密和 AI 前沿都有实质判断的人。

**Agentic Finance 的核心论点**：现有支付体系对 agent 根本行不通。刷卡每笔最低 30 美分手续费，而 Coinbase 观察到的 agent 电商交易中，76% 的金额低于 30 美分——这些交易大多是 agent 调取付费数据（如 paywall 内容、LinkedIn 信息）或 agent 之间互相调用的 tool call。Armstrong 的判断是：AI agent 不该是「无银行账户的（unbanked）」。Coinbase 已经做了一个工具，只需一条 prompt，agent 就能获得自己的加密钱包，无需 KYC。他们主导的 X402 协议已进入 Linux 基金会，Google、Cloudflare、AWS 都在跟进。

**Coinbase 内部的 AI 实践比外界预期的激进**：他们为每个服务、每个团队构建了「大脑」，内容包括历史事故记录、财务控制规则、所有 AB 测试、完整 PR 历史。每次 agent 改代码时先摄入这个大脑，人工修正后，修正内容写回大脑，形成递归自我改进系统——内部叫 Toshi。Armstrong 说他现在可以在 Slack 里 tag 一个 agent，几分钟后收到一个可以直接 review 的 PR，而不用一直 ping 团队：「这种感觉非常上瘾。」

**最反直觉的判断**：他不认为公司规模会因为 AI 大幅缩水，而是认为现有人员的输出速度将大幅提升——「被自动化的是任务，不是人」。

**关于代币化（Tokenization）**：Coinbase 的收入已有 88% 来自非比特币交易。他们刚推出了代币化股票产品（目前仅限美国以外地区），是首个真正 1:1 由托管证券支撑的 tokenized stock，而非合成品。他认为全球有 40 亿人没有美国券商账户，这是比稳定币更大的市场机会。

**关于 New Limit**：公司正在通过表观遗传重编程研究细胞年龄逆转，已在人源化小鼠模型中成功完成至少一种人类细胞类型的重编程，将于明年启动首个一期临床试验，适应症是酒精性肝病（ALD，确诊后 12 个月生存率极低）。长期愿景是让健康人也能通过一套疗法逆转各个器官的细胞老化——「目标不是做一个肝脏药，而是解决老化这个元问题」。

> "我们不希望 AI 成为没有银行账户的存在。如果我们要给 AI 开户，它们也理应获得金融服务。"
