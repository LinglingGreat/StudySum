### No Priors — Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan

**嘉宾**：Maxim Bar Kogan，Onyx Security 联合创始人兼 CEO

**核心议题：谁来监管 AI agent？**

Onyx Security 的核心产品是"守望 AI 的 AI"——训练专门的模型来监督企业中其他 agent 的行为。Maxim 的判断：随着 agent 执行的动作数量指数级增长，传统的"人工审核"根本无法扩展。当你有百万倍的 AI 动作时，人在回路（human-in-the-loop）就不再现实了。

**真实风险已经发生**：他列举了最近的案例——agent 意外发布了本不该公开的代码和 token，agent 自主行为导致系统宕机。企业意识到风险在指数级上升，但又无法阻止 AI 的采用，因此必须有机制来降低 agent 行为出错的概率。

**产品形态**：Onyx 将这种能力产品化为"AI 控制平面"（AI Control Plane）——接入企业内所有 AI agent，实时监控它们的行为是否合法合理。

**一个有意思的张力**：企业愿意让 Anthropic/OpenAI 训练守护 agent，但不愿意把 agent 的历史行为数据提供给这些公司——因为他们清楚这些数据饥渴的公司会用来训练模型。这给了 Onyx 这样的第三方安全公司生存空间。

**创业时机的运气成分**：Maxim 坦言，如果 Claude Code 等真正被广泛使用的自主 agent 再晚出现一年，Onyx 可能就撑不到现在了。
