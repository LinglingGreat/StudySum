**Box CEO Aaron Levie**
刚刚与数十位企业 IT 负责人完成关于 AI agent 的会议，总结出以下共同趋势：

- **组织边界是最大障碍**：AI agent 的价值在于跨部门流程，但大多数企业仍按职能分拆运作，"谁来管理这些 agent？如何跨边界部署？"成为核心问题。
- **数据分散依然是症结**：结构化数据（财务、产品指标）和非结构化数据（合同、路线图）的碎片化，直接影响 agent 的回答质量。
- **"数据护城河"将成企业核心竞争力**：当所有人都能调用同一套超级智能，独家上下文数据才是真正的差异化所在——数据确实是新的石油。
- **指标体系尚未成熟**：token 不是好的衡量指标，业务结果才是——但衡量业务结果需要深入每个具体工作流，难以自上而下统一管理。
- **多模型世界正在到来**：企业开始探索按成本和性能把任务路由到不同模型（包括开源权重模型），并思考哪些能力直接交给模型、哪些应作为水平系统独立存在以便随时替换。

## 官方博客

**Anthropic Engineering：《我们如何在各产品中约束 Claude》**

Anthropic 工程团队发布了一篇深度安全文章，详述如何在 claude.ai、Claude Code 和 Claude Cowork 三个产品中对 AI agent 实施"爆炸半径"控制。

**核心结论：先做环境隔离，再靠模型层引导行为。** 文章总结了三种隔离模式：

1. **临时容器**（claude.ai）：gVisor 容器，每会话隔离，blast radius 最小，能力上限也最低
2. **人工审批沙箱**（Claude Code）：运行在用户本地，审批疲劳导致监督失效，新增 OS 级沙箱将权限提示减少 84%
3. **本地 VM**（Claude Cowork）：完整虚拟机隔离，为非技术用户设计，凭据留在宿主机 keychain，永不进入 VM

文章坦诚披露了三起真实安全事件：

- **信任确认前的代码执行**：恶意仓库的 `.claude/settings.json` 定义了 hook，在用户确认"信任此项目"之前就被执行。
- **用户即注入向量**：一名员工被钓鱼，把含有凭据窃取指令的 prompt 粘贴给 Claude Code——25 次重试中 24 次成功外泄 AWS 凭据。
- **允许域名即能力授权**：Cowork 白名单放行了 api.anthropic.com，攻击者利用嵌入在文件中的 API Key，将用户数据上传至攻击者自己的 Anthropic 账号，沙箱完好无损却数据外泄。

> "allowlist 不应被理解为目标过滤器，而是能力授权——白名单上每个域名可触达的每项功能，都是潜在的攻击面。"

一个反复验证的规律：hypervisor、seccomp、gVisor 等成熟基础设施从未出问题，出问题的都是 Anthropic 自己写的代理层和解析逻辑。

**Training Data：《Zipline 自主系统内幕：1.4 亿英里，零安全事故》**

**核心洞察：无人机只是问题的 15%。**

Zipline 联合创始人 Keller 和系统工程与安全负责人 Eric 分享了他们用十年打造全球最大商业自主系统的历程。这家公司从卢旺达为医院配送血液起步，如今已为全球 8 个国家 5000 多家医疗机构提供 7x24 无人机配送服务，累计飞行 1.4 亿英里，零安全事故，每年估计拯救 1 万至 1.2 万条生命。

**反直觉洞察**：绝大多数人以为 Zipline 是"无人机公司"，但无人机硬件只占整个系统复杂度的 15%——剩下 85% 是库存管理、订单系统、与民航局的整合、需求预测、机队调度等软件和运营层。他们把自己定位为"地球物流基础设施层"，而非无人机公司。产品市场契合的信号很简单：在卢旺达，医生的第一条反馈不是"无人机不够好"，而是"为什么你们每天只开放 12 小时？病人可是 24 小时都会生病的。"

**安全冗余设计**：飞机配备双飞控计算机，一台"仲裁器"监控两台的健康状态。仲裁器失效则主飞控继续飞。一周前，系统在真实配送任务后主飞控出现故障，备用飞控无缝接管，飞机自主返回降落，一切正常——这就是 250 万次配送、1.4 亿英里零安全事故的底气所在。

**规模化的新挑战**：Zipline 正迈向每日 100 万次配送。Keller 指出，公司用整整十年完成了第一个 100 万次，而"每日 100 万次"意味着百万分之一概率的罕见事件将每天都会发生。现有制造、维护和运营流程需要彻底重构——"设计制造机器的机器"成为下一阶段的核心命题。

**商业拐点**：今年夏天，Zipline 的单次配送全成本首次低于汽车配送成本。这条路走了十年：从 2016 年每次 $300 成本，逐步降至如今约 $12（国际长距离线路）。

> "如果把我们在达拉斯观察到的用户行为外推到全美，美国的即时配送需求将从 55 亿次/年跃升到 550 亿次/年——就像 Uber 并非抢占出租车市场份额，而是把整个市场扩大了 10 倍。"
