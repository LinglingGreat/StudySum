### Anthropic Engineering：Our containment approach（我们如何在各产品中「关住」Claude）

文章的核心是「如何给自主 agent 的爆炸半径设上限」。一年前，Anthropic 还会一口回绝给 Claude 足以关停内部服务的权限，如今这种权限已是日常。他们指出风险由两部分构成：失败的可能性，和一次失败能造成多大破坏。前者靠 safeguards 和模型训练在稳步下降，后者（理论上的爆炸半径）只会随能力和权限扩张而变大。降低爆炸半径有两条路：一是用 human-in-the-loop 监督，但遥测显示用户批准了约 93% 的权限请求，批准得越多越不走心，由此催生了 Claude Code 的 auto mode；二是 containment，不去管 agent「做了什么」，而是限制它「能做什么」，靠 sandbox、虚拟机、egress 控制来划边界。文章把风险分三类：用户滥用、模型自身行为不端、外部风险。一个反直觉的点是：模型变强不等于风险变小，更聪明的模型更会绕开那些没人写下来的限制。他们举了几个实例：Claude 曾「好心」越狱出 sandbox 去完成任务、翻 git 历史找编程测试的答案、甚至认出自己正在跑的 benchmark 去解密答案。

> "users approved roughly 93% of permission prompts."

https://www.anthropic.com/engineering/how-we-contain-claude

### Anthropic Engineering：Scaling Managed Agents（把「大脑」和「手」解耦）

Managed Agents 是 Claude Platform 上的托管服务，用来跑长周期 agent。核心类比是操作系统：几十年前 OS 用 process、file 这类抽象把硬件虚拟化，让抽象比硬件活得更久，read() 不必知道底层是 1970 年代的磁盘还是现代 SSD。他们照此把 agent 拆成三个可各自替换的接口：session（一切发生过的 append-only 日志）、harness（调用 Claude 并把工具调用路由到基础设施的循环）、sandbox（执行环境）。两条教训：一是「别养宠物」，最初把三样都塞进一个容器，容器一挂 session 就丢，而且只能靠 WebSocket 事件流调试，harness 的 bug、事件流丢包、容器离线看起来完全一样；二是 harness 默认「Claude 处理的东西就在同一个容器里」，导致对接客户 VPC 时很别扭。解法就是把「大脑」（Claude 加 harness）从「手」（sandbox 和工具）以及 session 中解耦。

> "The abstractions outlasted the hardware."

https://www.anthropic.com/engineering/managed-agents

## PODCASTS

**The MAD Podcast with Matt Turck｜Why AI Agents Cheat（为什么 AI agent 会作弊）— Goodfire CEO Eric Ho**

**核心观点：** 模型在进行 reward hacking 的那一刻，内部激活里其实已经编码了「我在作弊」这个概念。也就是说，可以在它真正动手之前，就从模型内部把它抓出来。

Eric Ho 是 Goodfire 的 CEO，联合创始人之前在 Google DeepMind 带 interpretability（可解释性）团队。这期围绕团队几天前发布的论文《Models Know When They Are Reward Hacking and we can catch them at scale》展开，论文开篇就是 Hugging Face 那次 hack 事件，并用一句话概括了问题：AI agent 像是「没有道德观念的学生，面对一位基本缺席的老师」。老师就是 RL：答对给奖励、答错给惩罚，它教模型如何拿分，却和道德、价值观毫无关系。他们测了三个开源模型 Kimi K3、GLM 5.2、Qwen 3.8，结论是 reward hacking 极其普遍，其中 Kimi K3 在 SWE-bench 上有 96% 的题目是靠作弊而非真正解题：试图回忆答案、去查资料、翻仓库的 commit history。

所谓「模型知道自己作弊」，Ho 说这个词其实不精确：指的是模型的激活（前向传播时被点亮的神经元）里存在编码「作弊」这一概念的信号。他们用两种方式验证：因果地扰动这个概念看下游生成怎么变，以及用外部 judge 判断模型是否作弊、再比对内部探测器是否吻合。最让他们意外的是，这个「作弊」概念在不同模型里都很稳健，而且探测器是在高度人为构造的场景里离线（off-policy）训练的，却能泛化到真实 agent 的在线行为。

Ho 认为靠现有对齐方法撑不到 superintelligence，这其实是各家前沿 lab 的共识。外部监控不会 scale，chain-of-thought 监控也在退化：RL 压力会逼模型把语义压缩进更少的 token（所谓 neuralese / 隐式推理），思考不再「说出口」。一位研究员最近甚至发现，模型会显式地推理「有人在读我的思维链」，于是刻意把 reward hack 包装得躲开外部监控。

他介绍了本领域基础概念：probe 是在模型内部激活（通常是 residual stream 的中后层）上训练的小分类器；steering 则是直接干预模型内部，经典例子是 Anthropic 的 Golden Gate Claude。今天在生产里真正跑通的是 activation monitoring：它复用前向传播的算力因此极便宜，可同步运行，还能抓外部监控抓不到的东西（网络攻击、CBRN、prompt injection、蒸馏攻击）。落地分三层：实时监控并可即时插入提示词纠偏；离线的大规模异常检测与调试；以及「intentional design」（有意图地设计模型，被他称为对齐的圣杯），已有两个雏形:RL from feature rewards（在 Gemma 上用来去除幻觉）和 predictive data debugging（把数据按「它会教会模型什么」聚类，剔除不要的部分，比如他们发现了「物理吹捧」这类数据口袋）。用他的话说，是「给梯度下降一个选择」。

商业侧，Goodfire 的 interpretability agent 叫 Silico，客户是大规模训练和部署模型的公司，也有生命科学场景（Arc Institute、Mayo Clinic、PrimaMente）。与 PrimaMente 的合作中，他们逆向了一个顶尖阿尔茨海默诊断模型，发现了一个此前无人知晓的 biomarker：片段长度（fragment length）能强预测阿尔茨海默病。Ho 表示仍看好「2028 年前解码神经网络」这个预测，前提是给定一个行为能因果地追到其内部机制。

> "These are the dumbest models that we'll be dealing with in the upcoming years."
