**Claude Blog：在 Apple 平台通过 Foundation Models 框架集成 Claude**

Anthropic 发布了新 Swift package，让 Apple 开发者可以通过 Apple 的 Foundation Models 框架调用 Claude，处理需要多步推理、代码生成等复杂场景。

架构逻辑清晰：用 Apple on-device 模型（通过 `@Generable` 注解返回结构化 Swift 值）处理快速本地任务，当任务超出本地能力时无缝切换到 Claude——Claude 还支持联网搜索和代码执行。整个链路对用户透明，体验是连续的。一个典型示例：学习 App 在本地解释概念定义，当学生追问"这和之前学的有什么联系？"时，自动交由 Claude 处理。

目前支持 iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watchOS 27，明天正式上线。

## 播客

**The MAD Podcast with Matt Turck：如何构建长程 AI Agents — Basis 联合创始人 Mitch Troyanovsky**

**核心洞见**：eval 全部通过不等于 agent 真的可靠——如果它用错误的方式得到了正确答案，在真实生产环境里迟早会出问题。

Basis 是一家独角兽 AI 公司，其 agents 能自主运行数小时乃至数天，已经可以端到端完成企业税务申报等复杂任务。Mitch 分享了大量第一手经验，其中不少观点出人意料。

**长程 agent 的本质限制**：LLM 拥有极大的"工作记忆"，但天生没有短期或长期记忆。任务一旦超出单个上下文窗口，agent 就必须像电影《记忆碎片》里的主角那样，主动为"下一步"的自己留下笔记。Opus 3 是第一个真正在长上下文中"理解"而非"遗忘"的模型；o1 和 o3 带来了推理质量的飞跃，让 agent 有了自我纠错的能力。

**行为规范（Behavior Specs）**：Basis 用 Markdown 文件定义 agent 的行为方式——不只是"做什么"，还有"用什么方式做"。核心例子：税务研究必须引用 IRS 原始来源，不能从维基百科或博客摘取答案，即便结果完全正确。"就算答对率是百分之百，如果靠的是去维基百科，会计事务所不会雇这个员工，我们的 agent 也不该这么做。"这套 Spec 既是 agent 的行为指南，也是团队内部对"产品标准"的共识。目前 Basis 已和 BrainTrust 合作将这套方法开源。

**给 agent 开发者的一个清醒认识**：很多 builder 对代码整洁程度极度在意，却对 context 的质量漫不经心。但实际上 context 质量直接影响运行时性能，代码整洁与否不影响。英文是比代码更珍贵的东西。

**关于技术护城河**：Mitch 直言，技术护城河不是真正的护城河。Basis 的长期价值不依赖某个秘密 RL 技巧，而在于 AGI 到来之前深度嵌入市场——"客户买的不是有史以来最棒的税务申报，他们买的是一致性、可靠性，以及可以逐步信任和托付的感觉。"
