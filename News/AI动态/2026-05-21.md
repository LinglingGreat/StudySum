## OFFICIAL BLOGS

**Anthropic Engineering：Scaling Managed Agents: Decoupling the brain from the hands**

核心思路：将 agent 的"大脑"（Claude + harness）与"双手"（sandbox、工具）及"记忆"（session log）彻底解耦，三者各自独立、可独立替换。

过去将所有组件放在同一容器内导致三大问题：容器崩溃即丢失 session（"宠物问题"）；harness 与用户数据混居、无法安全调试；无法将 Claude 接入客户私有 VPC。

新架构将 session 独立持久化存储、harness 无状态化、sandbox 变成标准工具调用接口 `execute(name, input) → string`。直接收益：p50 首 token 延迟下降约 60%，p95 下降超 90%。安全性也提升：Claude 运行的 sandbox 与凭证彻底隔离，消除了 prompt injection 获取 token 的攻击面。

这篇文章用操作系统抽象的视角来理解 agent 架构设计，值得深读。

https://www.anthropic.com/engineering/managed-agents

**Claude Blog：New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels**

两项新功能正式推出。一是自托管 sandbox：企业可将 Claude agent 的工具执行部分运行在自己的基础设施或指定的沙箱云服务商（Cloudflare、Daytona、Modal、Vercel）上，敏感文件和服务不离开企业边界，agent 编排逻辑仍在 Anthropic 侧运行。二是 MCP tunnels（研究预览）：无需公网暴露即可将私有 MCP 服务器连入 agent，轻量 gateway 建立出站连接，流量全程加密，不需要入站防火墙规则。

## PODCASTS

**Training Data：Rebuilding IT From the Ground Up for the AI Age**
嘉宾：Serval 创始人兼 CEO Jake Stauch
https://www.youtube.com/watch?v=j7ypvRUFY7M

**核心观点：** 如果自动化比手动操作更难构建，人们永远会选择手动——所以企业 AI 的突破口不是更强的模型，而是让"建自动化"本身变得比"做这件事"更简单。

Jake 在构建的是 AI 原生的企业服务管理平台（类 ServiceNow），核心创新是 cogen 引擎：用自然语言描述工作流，AI 实时生成 TypeScript 代码，部署几乎零时延。数据库同理——描述你要从哪些来源取什么数据，系统自动生成抓取代码并持续更新。

**几个值得关注的判断：**

**护城河在边界，不在能力**：Jake 认为大模型能力已不是瓶颈，企业真正的问题是"怎么让模型在安全边界内运行"。Serval 的产品重点因此是权限管理、审批流、API 范围限制、审计日志——这些"老旧的企业软件东西"——而这恰好让他们在模型升级时受益而非受损。

**模型选型有讲究**：用户交互用 OpenAI 模型效果更好，代码生成（cogen）则 Anthropic 的 Sonnet、Opus 更优。他们持续跑 eval，但新模型并非总是更好——有时 prompt tuning 在新模型上失效，反而需要回退旧版。

**AI 拥有每个职位的"优先拒绝权"**：Serval 内部没有 SE（解决方案工程师），没有 SDR。所有职能先假设 AI 可以完成，再决定是否引入真人。招聘原则是"fewer, better"——他们认为在 AI 时代，能快速自我颠覆的小团队比臃肿组织更有优势。

**个人与组织的自主权张力**：员工希望 agent 权限越大越好，企业 IT 则恰恰相反。Jake 认为这是 AI 企业采用的核心矛盾，Shadow IT 历史会重演——当年 iPhone 绕过 IT 进入企业，最终 IT 接受并拥抱；现在 AI 工具正在重演同样的故事。

> "产品就是边界。产品实际上是限制模型能力的那些东西。"
> *"The product is the controls. The product is actually what limits the capabilities of the model."*
