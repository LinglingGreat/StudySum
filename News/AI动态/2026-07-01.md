**Anthropic Engineering：Claude Code 质量问题复盘报告**

Anthropic 公布了近期影响 Claude Code 的三个独立问题的根因分析：

1. **默认推理精度下调**：3 月 4 日为解决超长延迟，将默认推理精度从 `high` 调为 `medium`，但导致用户普遍感知智能下降，4 月 7 日已回滚。现在 Opus 4.7 默认 `xhigh`，其他模型默认 `high`。

2. **缓存优化 bug 导致 thinking 丢失**：3 月 26 日上线的优化原本应在会话空闲超 1 小时后清除一次旧的 thinking 历史，但 bug 导致此后每一轮都清除，使 Claude 表现出健忘、重复和奇怪的工具调用行为，4 月 10 日已修复。

3. **系统提示词限制回复长度**：4 月 16 日随 Opus 4.7 上线的 verbosity 控制指令（要求工具调用间文字 ≤25 词），在更大范围 eval 中显示导致编程质量下降约 3%，4 月 20 日已回滚。

后续改进：扩大内部 dogfooding 正式公开版本的使用比例，改进 Code Review 工具，并对每次系统提示词变更执行更严格的 eval 流程及灰度发布机制。

**Anthropic Engineering：Managed Agents 架构详解——将大脑与双手解耦**

Anthropic Engineering Blog 深度拆解了 Managed Agents 的核心架构决策。旧架构将 harness（大脑）、sandbox（双手）和 session（会话记录）放在同一个容器里，容器即"宠物"：出问题难以调试，且客户网络必须与 Anthropic 对接才能使用私有资源。

新架构将三者完全解耦：

- **Harness 离开容器**：通过 `execute(name, input) → string` 调用任意工具，容器变成"牲口"，失败直接换新的，无需人工维护
- **Session 独立存储**：harness 崩溃后通过 `wake(sessionId)` + `getSession(id)` 即可恢复，会话记录永久保存且可随时回溯
- **安全隔离**：生成代码的 sandbox 永远无法访问认证凭据；Git token 在 sandbox 初始化时注入 git remote，MCP OAuth token 存于 vault 并通过专用 proxy 调用
- **性能提升**：容器仅在需要时按需启动，p50 首 token 延迟下降约 60%，p95 下降超 90%

这一设计让 Managed Agents 可以在不改动接口的前提下，支持未来"一个大脑驱动多个双手"的多 agent 场景，也允许客户将 agent 接入自己私有网络内的资源。

https://www.anthropic.com/engineering/managed-agents

**Claude Blog：Managed Agents 新功能——自托管 sandbox 与 MCP tunnel**

Claude Managed Agents 现已支持两项新能力：

- **自托管 sandbox**（公开测试版）：agent 的工具执行环境可运行在用户自己的基础设施或 Cloudflare、Daytona、Modal、Vercel 等托管 sandbox 提供商，敏感数据和服务不离开企业边界，用户自行控制计算资源的规格和镜像
- **MCP tunnel**（研究预览版）：agent 通过轻量级 gateway 访问私有网络内的 MCP 服务（内部数据库、私有 API、知识库、工单系统等），无需开放公网入口，流量全程加密

Amplitude（设计 agent）、Clay（GTM 工程 agent）、Rogo（机构金融分析 agent）等企业已在各自场景落地这些功能。

**No Priors：英特尔 CEO 陈立武谈半导体供应链重构**

**核心观点：** 半导体行业正从"没人想投"走向战略必争，而 agentic AI 的爆发让 CPU 需求重新崛起。

陈立武（Lip-Bu Tan）是马来西亚出生、MIT 毕业的工程师，曾执掌 Cadence 15 年，期间股价从 2.42 美元涨至离任时的 85 倍。如今他在 66 岁接手英特尔，坦言"大家以为我该退休了"，但他认为英特尔对美国半导体生态的重要性让他无法拒绝。

**关键洞察：**

- **CPU 的再崛起**：过去训练端 CPU:GPU 比约 1:8，但 agentic AI 场景下 orchestrating agents 和强化学习更适合 CPU，这一比例已接近 1:1，甚至 1:1。"我很开心，现在我的 CPU 需求非常旺盛。"

- **与 Elon Musk 合作 TeraFab**：Musk 想自建晶圆厂，英特尔将提供技术支持并双方协同生产。陈立武说 Musk 会质疑每一个传统做法，"非常 unconventional，这正是我喜欢的。"

- **为何坚守 Foundry**：美国本土制造对供应链韧性至关重要，不能只依赖一两个地区。英特尔已从 18A 推进到 14A 量产，规划中已有 10nm 和 7nm；高级封装（Advanced Packaging）将成为下一个关键瓶颈。

- **新材料赛道**：CMOS 接近物理极限，陈立武已布局氮化镓、碳化硅、磷化铟，以及玻璃基板（散热）和人造金刚石（下一代绝缘材料）。

- **AI 辅助 EDA**：设计工具是"金矿"，AI 可显著提升 timing 优化和 tape-out 效率，看好这一方向的创业机会。

- **投资方法论**：永远从"这里的瓶颈是什么"出发，找到真实客户需求（首选超大规模云厂商），再下注。10 家被投公司里 9 家中途改过商业计划，所以要投团队，而不是单个创始人。

> "如果看十年后，什么样的公司会赢？聚焦一个细分领域、找对合伙人、能够规模化的公司。"
