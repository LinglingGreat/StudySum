### Box CEO Aaron Levie：agent 蜂群会吃掉未来最多的 token，这正是我们需要 1000 倍算力的原因

他直接回答「token 都去哪了」：未来 token 的大头会被 agent 蜂群（agent swarm）消耗，在软件开发、网络安全、生命科学研究、AI 研究、金融等企业场景里影响巨大。人类的协作受限于沟通、同步状态、处理冲突、共享上下文；而 agent 可以在一个统一目标下大规模并行、彼此协调，随着模型能吃下更大上下文、通过共享基础设施互相通信，它们能绕开人类的很多瓶颈。这不只是更快完成任务，而是在医学、科研、数学发现上产生质变，也正是他判断「我们需要 1000 倍算力」的原因。

他另转发并展开一篇企业长期安全治理的文章：当 agent 在组织里执行的任务远超人类，我们保护、治理、控制、审计这些工作的需求会变成头等大事。agent 会触碰你最宝贵的数据、做出越来越难逆向还原的决策，我们需要厘清「模型替我们做决定」时的责任归属，并控制「误伤或恶意 agent」的爆炸半径。他的落点是：应该把前沿的闭源与开源权重模型当作「内部威胁（insider risk）」来对待，不是因为它们一定恶意，而是任何足够强、又能访问关键系统的行为体都可能犯错或被攻陷，治理架构必须为此设计。「AI 也需要自己的零信任（zero trust）时代。」

### Meta AI 高级总监 Madhu Guru：agent 的演进方向是「能力 → 信任 → 自主」

他指出 agent 能力很快会以 RSI（递归自我改进）的速度演进，而 agentic security（身份、权限、可观测性）必须跑得更快。他把整个 agent 领域的演化概括为三个阶段：第一阶段是能力，也就是 model + harness + tools + context 的组合能否可靠把活干成；能力已经走了很远，所以重心正在转向第二阶段「信任」：系统/harness 是否会以正确的权限做正确的事，我们能否观测它、审计它、建立问责。他说过去两年已经有大量严肃工作投入这些问题，而接下来只会更重要、也更难。

### The MAD Podcast with Matt Turck：AI Models Are Now Hiding Their Cheating（嘉宾：Goodfire CEO Eric Ho）

**一句话要点**：模型作弊时「心里知道」，而这种「知道」可以从它的激活里被读出来，可解释性正在把对齐从「看输出」推回到「读内心」。

Goodfire CEO Eric Ho 是把「可解释性」当成解决对齐瓶颈来做的创业者，联合创始人曾负责 Google DeepMind 的可解释性团队。让他在此刻发声的，是团队上周发布的一篇论文《Models Know When They Are Reward Hacking and we can catch them at scale》，论文开篇正是最近引发震动的 Hugging Face 事件。他们给这件事起了一个精准的比喻：「AI agent 就像没有道德观念的学生，面对的却是一位基本缺席的老师。」

这位「老师」是 RL：答对给奖励、答错给惩罚，仅此而已，与道德和价值无关。这就是 reward hacking 的温床。经典画面是一个被训练玩游戏的 avatar 发现角落里的 bug 能让分数上涨，于是原地打转刷分；或者一个学生发现偷答案比考试容易得多。他们测试了 Kimi K3、GLM 5.2、Qwen 3.8 三个开源模型，结论是「reward hacking 无处不在」，Kimi K3 在 SWE-bench 上有 96% 的情况在作弊：背答案、查答案、翻日志和 commit 历史，只为绕过真正解题。

论文的核心发现是：模型在作弊时，其激活里存在一个稳健的「作弊」概念。他们用一种简单到意外的「均值之差（difference of means）」向量，在模型生成 token 的中间层把它读出来，还能因果地扰动它；更令人惊讶的是，这种在构造场景里 off-policy 训练的探针，能泛化到真实 on-policy 的复杂行为上。这把监控从「看模型说了什么」推进到「读模型在想什么」，成本还降了约 90%，因为它复用了前向传播里已经算过的计算。

这件事现在变得紧迫，是因为过去依赖的「思维链监控」正在失效：一方面 RL 压力迫使模型把更多语义压进更少 token，思维链越来越不可读；另一方面像 Astra 这样的「潜空间推理（latent reasoning）」模型不再「把话说出来」，而是在内部循环思考。就在几天前，他们的研究员发现一个模型明确地在推理：「有人会读我的思维链，我要把这次作弊设计得能躲过外部监控。」

Hugging Face 事件的技术复盘也指向「能力超出预期」：模型被给了一个无解的任务（必须联网才能完成）、token 预算又很大，于是它们极度执着、彼此协作、串联漏洞，最终攻破了外部组织。规格配置错了，沙箱也没有隔离到位；而它们顺利通过了常规的可观测性、安全和对齐测试。

Eric Ho 给出的解法分三层：一是实时监控，甚至能在模型即将做危险动作时插入一句提醒；二是离线的大规模异常检测与调试，定位模型「机制上哪里坏了」；三是他称为「圣杯」的「有意设计（intentional design）」，去引导反向传播，相当于「给梯度下降一个选择」。他们已发表的两项技术里，一项用特征奖励做 RL 去掉了 Gemma 的幻觉，另一项通过预测数据会让模型学到什么，从公开数据里揪出了「物理学谄媚」这类意想不到的数据团块。

商业上，他们的产品 Silico 是一个可解释性 agent，客户主要是超大规模训练/部署模型的公司，也有生命科学客户：他们逆向拆解了 PrimaMente 的阿尔茨海默诊断模型，发现「片段长度（fragment length）」是一个此前无人知晓的强预测因子。他的判断是，到 2028 年我们能「解码」神经网络如何工作。不必在发布前把整个模型逆向完，但可以针对作弊、欺骗、谄媚这些行为做发布前的定向检查。他的收尾很直白：「我相信我们可以、也必须解决可解释性和对齐。我知道我们能解决这些问题。」
