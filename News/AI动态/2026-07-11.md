## 播客

### The MAD Podcast with Matt Turck
**Stripe's AI Chief: How AI Agents Will Buy, Sell, and Pay**

**核心洞见：** Token 盗窃是当前 AI 行业最被低估的威胁，而 agent 将从根本上重塑整个商业经济栈。

Stripe 数据与 AI 负责人 Emily Sands 与主持人 Matt Turck 深入探讨了 agentic commerce 的现状与未来。Emily 长期处于支付基础设施与 AI agent 经济的交叉点，掌握大量独特一手数据。

**反直觉洞见一：Token 盗窃是 AI 最大的未被讨论问题**

传统诈骗盗的是钱或凭证，AI 时代的诈骗者直接盗 token。Emily 分享了令她震惊的数据：AI 公司超过六分之一的注册用户涉及 token 滥用。具体形式包括：多账户刷新新用户积分、免费试用期间消耗完所有 token 后从不转化、以及按用量结算前"吃霸王餐"后消失。更隐秘的手法是：盗用 token 后克隆产品再低价出售，或批量生成音乐上传 Spotify 赚取版税。在 SaaS 时代，这类欺诈几乎没有意义（边际成本为零）；但在 AI 时代，每笔 token 消耗都有真实成本，欺诈率一旦偏高，公司的经济模型会迅速崩溃。

**反直觉洞见二：Vibe coding 已解决，Vibe deployment 才是瓶颈**

Stripe 文档的 agent 流量一年内增长超 10 倍，现占文档总流量的 40%；CLI 工具 70% 的 API 请求来自 agent 而非人类开发者。编码已不是障碍，部署才是：开发者仍需在十几个服务间手动复制粘贴凭证、逐一配置账户。为此 Stripe 推出了 Stripe Projects，让 agent 可以直接从命令行完成服务注册、配置和集成，合作伙伴覆盖 Vercel、Supabase、Cloudflare、Twilio、Clerk 等。

**反直觉洞见三：AI 正在催生大量"单人公司"**

美国目前有 500 万人以独立经营公司为主要收入来源，其中数十万人年收入超百万美元。2026 年通过 Stripe Atlas 注册的新公司，收入轨迹是 2025 年同期的 5 倍。AI 正在让"有想法的人"绕过技术壁垒，直接完成构建、部署、销售的全链路。新公司普遍从第一天起就覆盖十几个国家，国际化不再是规模化之后的事。

**关于 agentic commerce 的层级框架**

Stripe 内部已建立类似自动驾驶等级的 agentic commerce 分级体系：L1 是人类主导决策、agent 仅执行支付；L3 是 AI 推荐+一键结账（如 ChatGPT Instant Checkout）；最高级别是 agent 完全自主发现、购买、谈判，无人在回路。当前消费者侧普遍处于 L2，且主要集中在低中价格商品，信任建立仍需时间积累。

> "It's Emily has an agent who's tasked with running a business, and that includes buying some things and selling some things and making some profits. And that'll be the world that I would like to be talking about twelve months from now."

Emily 预判，未来 12 个月最值得期待的不是 agentic commerce 自动化程度从 L2 升到 L4，而是看到第一批真正作为"微型企业"运作的 agent：自主发现服务、购买、集成，再向外销售，形成完整的经济闭环。
