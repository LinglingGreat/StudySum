**Anthropic Engineering：Claude Code 质量问题事后复盘**

过去一个月用户反馈 Claude 响应质量下滑，Anthropic 追溯到三个独立问题：

1. **默认推理强度被调低**（3 月 4 日）：Claude Code 默认推理强度从 high 改为 medium，用户随即反馈变"笨"，4 月 7 日回退，现所有用户默认 xhigh/high。
2. **缓存优化 bug 导致失忆**（3 月 26 日）：本意是空闲超一小时后清理一次旧 thinking 以降低恢复成本，结果 bug 导致每轮都清理，Claude 越用越"健忘"，工具调用也出现异常行为。4 月 10 日修复。
3. **限制字数的 system prompt 损害编码质量**（4 月 16 日）："每次工具调用间文字不超过 25 词，最终回复不超过 100 词"这条指令与其他 prompt 叠加后，编码质量出现 3% 的可测量下降，4 月 20 日已回退。

三个问题影响的流量时段不同，叠加后表现像广泛且不一致的退化，难以定位。Anthropic 已于 4 月 23 日为所有订阅用户重置使用限额。

https://www.anthropic.com/engineering/april-23-postmortem

**Anthropic Engineering：Managed Agents——将"大脑"与"双手"解耦**

Anthropic 深度技术博客，解释 Managed Agents 架构的设计哲学：将 session（事件日志）、harness（调度循环）、sandbox（执行环境）解耦为三个独立接口，各自可独立替换，效仿操作系统虚拟化硬件的思路。

核心收益：p50 TTFT 下降约 60%，p95 下降超 90%；安全边界更清晰，sandbox 中运行的代码永远接触不到凭证；多脑多手成为可能，每个 brain（harness）通过工具调用触达 sandbox，不再强绑定于同一容器。文章以"为尚未被发明的程序设计系统"这一经典操作系统命题作为出发点，值得深读。

https://www.anthropic.com/engineering/managed-agents

**Claude Blog：Managed Agents 新功能——自托管沙箱与 MCP 隧道**

两个新能力：

- **自托管沙箱**（公测）：agent 的代码执行可运行在 Cloudflare、Daytona、Modal、Vercel 等托管方或自有基础设施上，敏感数据和执行环境完全留在企业内部，Anthropic 侧只处理模型调度和 session 管理。
- **MCP 隧道**（研究预览）：通过轻量网关将私有网络内的 MCP server 接入 agent，无需对外暴露端口，全程加密。适合连接内部数据库、私有 API、知识库等。

https://claude.com/blog/claude-managed-agents-updates

**AI & I by Every：微软 CTO Kevin Scott——为 Agent 而生的互联网**

原集标题：Microsoft's Vision for an Internet Made for Agents With CTO Kevin Scott

**核心判断**：AI 模型的推理能力已超过产品的实际使用程度——弥合这个"能力悬空（capability overhang）"才是当前最紧迫的任务，而非继续堆 scaling。

Kevin Scott 是微软 CTO，程序员生涯长达 41 年。他对当前 AI 形势有几个值得关注的判断：

其一，模型已足够强，产品还没跟上。他直言当前问题是"capability overhang"：模型的推理能力已经超过了我们把它用在产品上的程度，行业集体欠了一笔债，需要努力把能力真正转化为用户价值。

其二，agentic web 是今年的主题，MCP 相当于 HTTP。他在微软内部推动所有系统使用统一协议与 agent 对话，以避免"Conway 定律"——"你的组织架构会渗透进你的产品"。他认为 MCP 的简单性是其最大优势，安全模型（agent 身份、权限体系）也将围绕它逐步建立，无需封闭化。

其三，工具改变不等于放弃手艺。对于"用 AI 写代码是否丧失了工匠精神"的质疑，他类比木工工具的演进——用 CNC 还是手工刨不影响你是不是真正的木匠，关键是保持开放心态。"我后悔太晚接触 3D 打印机，我不想让好奇心在新事物面前关闭。"

其四，一年内 agent 交互将从同步转向异步。现在大家还是坐在那里等 agent 返回结果；他预测很快人们会把任务丢给 agent，agent 在后台跑完一大段、跨越多个系统，再把决策交还给人。
