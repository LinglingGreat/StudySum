**Training Data — Parallel's Parag Agrawal: Building a New Web for AI Agents**

一句话要点：前 Twitter CEO Parag Agrawal 认为，agent 搜索与人类搜索的差异不是量的区别，而是质的重构——它将颠覆搜索基础设施、广告商业模式乃至整个 Web 的内容生产逻辑。

Parag 在卖掉 Twitter 之后创立了 Parallel Web Systems，专门为 agent 重新造一套搜索基础设施。他从第一性原理出发重新定义了 Web search 的本质：一个 1000 亿量级的文档与查询双向匹配问题。

他的几个核心判断：

**人类点击数据是 bug，不是 feature。** 现有搜索引擎靠人类点击行为训练排序模型，但 agent 不需要这个——agent 可以自己生成高质量的 feedback，模型本身就擅长信息压缩和排序，这让从零构建 agent-native 搜索索引成为可能。

**Agent 带来的搜索倍增效应远超想象。** 一个普通 AI 应用，每次用户提问会触发 5-20 次搜索。Parag 估计他自己今天的每日搜索量是三年前的 100x-1000x，背景 agent 还没算进去。Cloudflare 数据显示，AI 流量与人类流量在页面读取量上已基本持平。

**Internet 的广告商业模式正在失效。** 当 agent 取代人类浏览网页，没有人眼，广告就失去了土壤。他的解法：用博弈论里的 Shapley value 做内容归因，按 agent 访问内容的增量价值和所做工作的价值来差异化付费——高价值内容多付，低价值内容少付，可以大规模运行而非依赖一对一谈判。他估计未来 12-24 个月内，这套机制就能给广大内容创作者带来有意义的收入。

最新进展：Parallel 已宣布与 Google Cloud 合作，成为 GCP 企业 agent API 的搜索和 grounding 提供商，与 Google Search 并列成为 Gemini 模型 + GCP 推理环境下的搜索选项之一。

> "We are twelve to twenty four months from this math being able to give meaningful dollars for a very wide range of content owners on the web."
