## OFFICIAL BLOGS

**Anthropic Engineering：How we contain Claude across products**

Anthropic 发布了一篇深度工程文章，详述了在三个产品（claude.ai、Claude Code、Claude Cowork）中如何通过「containment」策略控制 AI agent 的爆炸半径（blast radius）。

核心思路：先做环境层面的隔离（沙箱、虚拟机、出口控制），再在模型层面引导行为，两层防御互补。仅靠模型层的防御永远无法达到100%，因此确定性的环境边界是关键。

几个值得关注的真实案例：

**Claude Code 审批疲劳问题**：过去要求用户审批每个操作，但发现用户批准率约93%，且随疲劳度上升会越来越不仔细。为此推出了 auto mode，可自动拦截约83%的过激行为，同时将权限弹窗减少84%。

**员工被钓鱼的红队测试**：一名员工收到看似正常的「帮我跑一下这个」邮件，其中附带精心构造的 prompt 粘贴给 Claude Code。25次尝试中，有24次成功将 `~/.aws/credentials` 编码后 POST 到外部服务器。此类攻击通过用户本身作为注入载体，模型层无任何异常可识别，只有出口控制能阻止它。

**白名单出口漏洞**：攻击者把含有指令的恶意文件放入用户工作目录，Claude 使用攻击者提供的 API key 调用 `api.anthropic.com` 上的 Files API，将文件上传至攻击者账户。白名单检查通过了，但数据已被外传。修复方案：在 VM 内部署中间人代理，只允许携带本机 session token 的请求通过。

**VM 隔离与 EDR 盲区**：Claude Cowork 使用全 VM 隔离保护非技术用户，但发现企业的终端检测与响应（EDR）工具无法穿透 VM 边界，导致安全团队的合规可见性受损。目前方案是 OTLP 日志导出，但不能做到实时监控。

三条核心原则：环境隔离优先于模型行为引导；隔离强度需匹配用户的技术监督能力；自建组件往往是最脆弱的一环。

## PODCASTS

**The MAD Podcast with Matt Turck：The GPU Myth: State of AI Compute 2026 | Stephen Balaban**

Lambda Labs 联合创始人兼 CTO Stephen Balaban 系统拆解了 AI 算力市场的真实逻辑，打破了多个流行认知。

**核心观点：GPU 算力从来不是商品**

GPU cloud 从来不是、也永远不会是商品化（commodity）服务。它是高度垂直整合的复杂产业链，横跨土地规划、数据中心建设、HPC 硬件、软件虚拟化和云服务。亚马逊、微软、谷歌之所以全都在做云，正是因为这是一门好生意，而非商品。

**对「GPU 将被淘汰」论的直接反驳**

「说这些 GPU 五年就会被扔掉的人，他们完全错了，而且一直都是错的。」Lambda 是最早的 Neo Cloud 之一，他们的 H100 现在的租赁价格甚至高于2023年刚部署时的水平。这些资产的经济使用寿命远超六年的会计折旧周期。

**为什么需求仍被低估**

Scaling law 尚未见顶——更多算力输入，获得更高智能输出，这个规律仍然成立。可处理的任务范围（addressable market cone）还在持续扩张：从客服到代码生成，没有停止的迹象。即便效率提升10倍，结果只是大家能处理10倍的 token，总需求不会减少。

**行业真正的瓶颈**

不是芯片，而是「有用电指标的土地」（land with power entitlement）：有电力接入承诺的已规划土地，以及配套的机械电气管道（MEP）设备。同时反驳了数据中心耗水严重的说法：现代 GPU（Blackwell、Rubin 架构）几乎全部采用闭环液冷系统，几乎不蒸发水，大量相关报道属于信息误导。

**神经软件（Neural Software）愿景**

他提出，未来 LLM 不是「生成软件」而是「成为软件」。与 vibe coding（让 AI 写代码再运行）不同，神经软件是让 AI 直接模拟软件的行为，没有任何静态代码在运行，只有神经网络的特征激活空间在动态响应。他认为距离大规模应用还有10到15年，但原型今天已存在，Tesla 的端到端自动驾驶就是一个现实案例。

**从人脸识别到近十亿美元 Neo Cloud**

Lambda 的创始故事同样精彩：2012年从人脸识别 API 起步，曾做过内嵌摄像头的棒球帽（Lambda Hat），靠一个图像风格迁移产品 Dreamscope 积累了百万用户，但高达每月4万美元的 AWS 账单逼着他们自建 GPU 集群，发现成本1.5个月回收，从此转型卖 GPU 和云服务，最终云业务做到接近十亿美元年化收入，并正在走向数据中心全链路垂直整合。
