### Anthropic Engineering：Redesigning source control at Anthropic

Anthropic 自研了一套版本控制系统 Scion，用五个月把整个 monorepo 从 git 迁了过去。驱动因素是：写代码已经不再是瓶颈，为人类规模设计的开发者基础设施才是。2026 年 5 月他们日均合并约 2,500 次代码改动，到 9 月已超过 30,000 次/天，而且看不到放缓的迹象。主分支历史近 100 GB，压缩后的工作副本超过 25 GB，每天要做约 2,500 万次代码 checkout 供 CI 使用；按 git 的方式朴素拉取，一天就是 600 PB 以上的流量。

问题出在 git 的设计前提：每个 clone 都是完整、可离线自洽的仓库。但 Anthropic 的绝大多数客户端是 agent 和 job，按定义永远在线。于是他们问自己：如果从设计之初就假设「客户端永远在线」，源代码管理会长什么样？Scion 的几个核心原则：客户端永远在线；client-server 不对称（服务端回答历史与 blame、创建 commit、做 merge/rebase，客户端只保留有界的本地对象缓存）；一切必须可横向扩展（连服务端都不存在仓库的完整实体副本，也没有 packfile，因此无需仓库维护）；commit 要便宜、增量、无锁（在服务端完成，成本随改动大小而非仓库大小增长）；工作副本可选、按设计稀疏（用稀疏 checkout 和按需虚拟化的 checkout）。

数据单位是「changeset」（一条 write-ahead log 条目），只记录相对首个父节点的改动文件；其余如 blame、路径历史、提交图的 skip list 等统称 derived data，用一种递归的通用机制按需计算。7 人团队同时造出 Scion 和代码审查工具 Antique，外加半打相关系统，并完成迁移，期间日均合并量还涨了 10 倍。工程上的收获也很有意思：有一次他们把第一版 git 到 Scion 的入库管道手写出来，交给早期的 Claude Mythos Preview 重写，结果后者在无人指导的情况下产出一个内存少 20 倍、快 4 倍、且保留了所有隐含不变量的版本。所有参与该系统的工程师如今都认为 Claude 写代码比自己强，但工程师仍提供关键的跨系统理解与设计取舍；「很多时候，工程师的角色就是对 Claude 说不」。他们还用 Claude Tag 给每个组件各配一个「superfan」，像经验丰富的工程师那样盯着遥测和日志找异常。Anthropic 明说 Scion 不是 git 的通用替代品，只对超大 monorepo 有意义，会与 GitHub、GitLab 与开源社区分享思路。

https://www.anthropic.com/engineering/redesigning-source-control

### Training Data：David Silver and Lasse Espeholt of Ineffable Intelligence: A Superlearner for the Age of Experience

**一句话要点**：AlphaGo 之父 David Silver 认为通往超智能的路不经过 LLM，而要用能从经验里完全自主学习、并不断发现新知识的系统；他和 Lasse Espeholt 的新实验室 Ineffable Intelligence 的目标就是造出这样的 super learner。

David Silver 是 AlphaGo、AlphaZero 的核心人物，也是把深度强化学习推上世界舞台的人；Lasse Espeholt 早期在 DeepMind 做 Google Brain 之前，就做出了后来整个规模化 RL 的根基工作（IMPALA、SeedRL）。两人为何离开 DeepMind 另起炉灶，Silver 讲得很直白：世界已经有成千上万、甚至几十万顶尖研究者在用同一条 LLM 路线（预训练、后训练、coding），他不想去做「第 100001 个」。他相信还有一盏路灯没人照过，而那盏灯如果点亮，会改变整个 AI。

他们的核心赌注，是主动放弃人类先验和万亿级人类数据。Silver 用 AlphaGo 到 AlphaZero 做例证：AlphaGo 靠人类棋谱、靠人守在训练回路里，花了两年才击败李世石；而 AlphaZero 一旦放弃人类数据、让算法自己发现，几个小时就超越了那两年的成果，国际象棋四小时就击败了史上最强的 AI。他的原话是：「你必须放弃人类数据，才能让自己发现那些能一骑绝尘、不断学习下去的东西。」

做法上，他们一边造 super learner，一边造被称为「crucible」的环境（培养皿）：不手搓一堆谜题、也不精确指定「什么是科学」，而是给 agent 一个极其简单的目标，放进一个拥有海量涌现复杂度的世界，让它自己去发现。Silver 拿进化打比方：进化只是优化一个简单的适应度信号，却涌现出了生命的全部复杂度。他甚至认为人类语言不是推理的终点，从人类语言出发会连带带入我们关于「智能该怎么思考」的偏见。

算力上，他们是 GCP 上最大的 GPU 集群之一（基于 Vera Rubin 架构）的首批客户，一个机架基本可当作一台机器，节点间高带宽对 RL 快速迭代至关重要；模拟、训练、推理全放在 GPU 上。安全上，他不认为只靠监控语言就够了，提出 shadow action（看 agent「会」做什么但不让它真做）、用另一个超智能充当 monitor 等非语言手段。他的主张是：在模拟里尽可能快，在现实世界里谨慎前行，并用模拟中获得的「超智能科学」来为现实世界的推进设闸。团队刻意只招了 20 人，强调人均算力高、研究主导。

他给的时间表：一年内会看到「走在正确道路上」的极强证据，三到五年内实现真正的超智能，因为 coding agent 加速了进程，他已把预期提前到三年。
