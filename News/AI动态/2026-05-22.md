### AI & I by Every：《Stainless 内幕：Anthropic 刚以 3 亿美元收购的开发者工具创业公司》

**核心观点：** MCP（Model Context Protocol）是互联网为 AI 时代重新布线的基础设施，而能把 MCP 做好的公司将在未来十年赢得优势。

Stainless 创始人兼 CEO Alex Rattray（曾在 Stripe 负责 API 产品）深度拆解了 API 与 MCP 的本质区别与关联。他的核心比喻精准：**API 是互联网的神经突触**——没有它们，各系统之间就没有真正的信息交换，正如大脑里没有神经元连接就没有思维。

Stainless 目前服务于 OpenAI、Anthropic 等头部公司的 API 和 SDK 构建，并开始布局 MCP Server。Rattray 坦诚指出了 MCP 当前的核心挑战：**规模化困难且存在安全隐患**。他提出，现有的"让 AI 使用互联网"的范式可能需要一个更好的底层模型——这也正是 Anthropic 收购 Stainless 的战略逻辑所在：掌控 AI 与互联网交互的关键基础层。

> "APIs are the dendrites of the Internet... If you have two neurons in your brain but they're not talking to each other, you're actually not thinking."
