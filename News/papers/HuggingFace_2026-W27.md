## 1. Orca: The World is in Your Mind
**👍 307** · 🏛 智源研究院 · https://huggingface.co/papers/2606.30534 · GitHub: https://github.com/orca-wm/Orca

### 问题与动机
当前各类基础模型各自为政：语言模型优化「下一个 token」、视频模型优化「下一帧」、机器人策略优化「下一个动作」。这三条预测目标彼此割裂，没有一个统一的表示能同时支撑「理解世界、预测世界、作用于世界」。论文要解决的本质问题是：能否学到一个统一的「世界隐空间」（world latent space，把多模态世界信号压缩到同一套内部状态里），让不同下游任务都从这套状态读出。

### 方法与核心创新
核心是把建模目标从「预测下一个 token/帧/动作」改为「预测下一个状态」（Next-State-Prediction，统一的状态转移建模）。学习分两条互补路径：无意识学习（unconscious learning）从连续视频里捕获稠密的自然状态转移；有意识学习（conscious learning）用语言描述的事件和 VQA（视觉问答）监督来建模稀疏但有意义的状态转移。预训练用了 125K 小时视频 + 1.6 亿条事件标注这一超大规模「世界学习清单」。训练完后主干冻结，只训练轻量的模态专属解码器，把同一套世界隐空间读出到文本生成、图像预测、具身动作生成三个下游接口。

### 关键实验结果
在三个代表性下游读出上验证：主干冻结、仅解码器可训的前提下，Orca 超过同规模的专用基线模型，并展示了范式的可扩展性——「更强的世界隐空间带来更强的下游读出」。摘要以定性 SOTA 表述为主，未给出具体分数差（摘要未明确，推断）；最硬的量化信号是 125K 小时视频 + 1.6 亿事件标注的数据规模。

### 局限性与开放问题
摘要几乎未提供与基线的数值差距，「outperforms similar-sized baselines」的幅度不明。冻结主干 + 轻量解码器的范式虽然优雅，但读出质量是否受限于解码器容量、隐空间对精细动作控制是否够用，均未量化。作者自陈仍有诸多局限。

### 启发与应用前景
本周热度第一（307 赞），代表「世界基础模型」路线的一次系统尝试。把 next-state 作为统一目标，为多模态理解-预测-行动的一体化提供了清晰范式，对具身智能、机器人预训练有直接启发。开源代码 + 项目页（orca-wm.github.io）已放出，可 follow 的切口是把冻结主干换成更强底座、或验证隐空间在真实机器人闭环上的可迁移性。

## 2. Agentic Abstention: Do Agents Know When to Stop Instead of Act?
**👍 146** · 🏛 利兹大学 / 西南交通大学 / 华盛顿大学 / Allen Institute for AI · https://huggingface.co/papers/2606.28733 · GitHub: https://github.com/lhannnn/agentic-abstention

### 问题与动机
LLM Agent 被期望多轮调用搜索、浏览、终端工具去完成目标，但并非每个目标都「说清楚了」或「在当前环境里可完成」。一个可靠的 Agent 应当意识到「继续折腾也没用」并停手。论文定义了「Agentic Abstention」（智能体弃权）：在不确定下决定何时停止行动。与传统单轮「回答还是弃权」不同，这是一个序列决策问题——每一轮都可以回答、弃权或再收集信息，而「该弃权」这件事往往要与环境交互后才暴露。

### 方法与核心创新
论文不是提模型而是把问题形式化并大规模测量：横跨网购、终端、问答三类环境，评测 13 个 LLM-as-agent 系统 + 2 套 Agent 脚手架（scaffold，即驱动 Agent 的外层框架），任务量超 28,000。关键发现是「难点不只是能不能弃权，更是何时弃权」——有的 Agent 该停不停，有的则在大量无用交互后才停。进一步提出 CONVOLVE：一种上下文工程方法，把完整交互轨迹蒸馏成可复用的「停止规则」，无需更新模型参数。

### 关键实验结果
最有反差的发现是：模型规模、推理能力、脚手架对弃权的影响方向不一致——更大、更强的模型有时反而更不擅长「及时弃权」。在指令看似可行、直到环境揭示无解的任务上（如没有任何结果匹配指令），差距最大。CONVOLVE 在 WebShop 上把 Llama-3.3-70B 的「及时召回率」（timely recall，该停时准确停下的比例）从 26.7 提升到 57.4，翻了一倍多，且不动模型参数。

### 局限性与开放问题
CONVOLVE 的停止规则从轨迹蒸馏而来，其覆盖度受采样轨迹约束，对未见过的「陷阱式」任务是否泛化未知。「更强模型反而更差」的机制解释停留在观察层面，尚未给出因果归因（摘要未明确，推断）。57.4 的及时召回仍有大量漏判空间。

### 启发与应用前景
「知道何时停手」是可靠 Agent 落地被长期忽视的一环——生产环境里，无休止的无效工具调用直接烧钱且拖累体验。CONVOLVE「靠上下文工程而非训练」的路线复现门槛低，对客服、深度搜索、自动化运维类 Agent 有直接工程价值。数据集与代码已开源，可 follow 的角度是把停止规则从单任务泛化到跨域。

## 3. Program-as-Weights: A Programming Paradigm for Fuzzy Functions
**👍 117** · 🏛 滑铁卢大学 / 康奈尔大学 / 哈佛大学 · https://huggingface.co/papers/2607.02512 · GitHub: https://github.com/programasweights/programasweights-python

### 问题与动机
很多日常编程任务无法用干净的规则实现——比如从海量日志里报警重要行、修复格式坏掉的 JSON、按用户意图给搜索结果排序。这类「模糊函数」现在越来越多地外包给 LLM API，代价是失去本地性、可复现性，还要持续付费。论文要解决的是：能否把这类模糊函数从自然语言规格「编译」成一个紧凑、可本地离线执行的神经工件，一次生成、之后反复廉价调用。

### 方法与核心创新
提出 Program-as-Weights（PAW，程序即权重）范式：用一个 4B 参数的「编译器」模型，读入自然语言规格，直接产出参数高效的适配器（adapter，一小组可插拔权重），供一个冻结的轻量「解释器」模型执行。编译器在 FuzzyBench 上训练——这是论文同时发布的 1000 万样本数据集。最关键的范式转变是：把基础模型从「每次输入都要现场求解的问题解决者」重新定位成「工具构建者」——每个函数定义只调用编译器一次，产出的小工件之后每次函数调用都便宜且离线。

### 关键实验结果
最亮眼的数字：一个 0.6B 的 Qwen3 解释器执行 PAW 程序，性能追平「直接 prompt 一个 Qwen3-32B」——即用约 1/50 的推理显存，在 MacBook M3 上以 30 tokens/s 运行。也就是说，把 32B 大模型的一次性调用成本，摊薄成一个可在笔记本上离线跑的 0.6B 小工件，参数量差了 50 多倍而效果持平。

### 局限性与开放问题
「追平 Qwen3-32B 直接 prompt」是相对基线，未与其他蒸馏/微调方案横向对比。编译器 4B、解释器 0.6B 的组合能覆盖多复杂的模糊函数存在边界——超出 FuzzyBench 分布的任务能否编译成功、精度是否下滑，摘要未量化（推断）。适配器一旦生成即固定，规格漂移时需重新编译。

### 启发与应用前景
「一次编译、永久离线复用」直击 LLM API 的成本与隐私痛点，对边缘设备、本地化部署、隐私敏感场景极具吸引力。它把「foundation model as solver」翻转为「as compiler」，与本周 [6] Agents-A1「参数不是唯一杠杆」的思路呼应。代码 + 1000 万样本 FuzzyBench 已开源（183 stars），可 follow 的切口是把编译目标从模糊函数扩展到更结构化的工具生成。

## 4. Dockerless: Environment-Free Program Verifier for Coding Agents
**👍 108** · 🏛 上海交通大学 / 抖音集团 · https://huggingface.co/papers/2606.28436

### 问题与动机
程序验证器（判断生成的代码补丁对不对）在训练编码 Agent 中至关重要：既用于给监督微调（SFT）挑选高质量轨迹，也用于给强化学习（RL）提供奖励。但标准的「执行式验证」要在每个仓库各自的环境（如 Docker 镜像）里跑单元测试，环境搭建成本极高——每个仓库都要配依赖、装环境，规模化时是沉重负担。

### 方法与核心创新
提出 Dockerless：一个无需环境的智能体式补丁验证器，不执行代码就评判补丁对错。它不是简单地把候选补丁和参考答案做匹配，而是通过「智能体式仓库探索」收集证据来判断补丁正确性——像人 review 代码一样在仓库里查上下文、找依据。用它同时充当 SFT 轨迹过滤器和 RL 奖励，就能搭出一条完全无环境的后训练流水线，彻底绕开 Docker 搭建成本。

### 关键实验结果
在验证器评测基准上，Dockerless 比最强的开源验证器高 14.3 个 AUC 点（AUC 即 ROC 曲线下面积，衡量分类器区分对错补丁的综合能力，越接近 1 越好）。用它做全套无环境后训练，最终模型在 SWE-bench（软件工程真实修 bug 基准）三个子集上分别达到 Verified 62.0%、Multilingual 50.0%、Pro 35.2%，比 Qwen3.5-9B 基线高出 2.4、8.7、2.9 点，追平了基于真实环境执行的后训练效果。

### 局限性与开放问题
「不执行就判对错」本质是近似——对需要真实运行才能暴露的隐蔽 bug（如运行时竞态、数值溢出），证据探索可能漏判（摘要未明确，推断）。+14.3 AUC 虽显著，但验证器本身的误判会作为噪声注入 SFT/RL，长链训练下误差如何累积未讨论。SWE-bench Pro 35.2% 也说明难任务仍远未解决。

### 启发与应用前景
「用智能体探索代替容器执行」把编码 Agent 训练的环境成本从主要瓶颈变成可省去项，对大规模 RL 训练极具工程价值——省下的算力和运维可直接转化为更多训练数据。这与本周 [2] CONVOLVE「用轨迹证据代替执行」的思路同源，都在探索「无需真实环境也能可靠评判」。摘要未提开源，可 follow 的切口是把无环境验证扩展到更多语言与运行时敏感场景。

## 5. DOPD: Dual On-policy Distillation
**👍 103** · 🏛 新加坡国立大学 / 香港中文大学 / 北京大学 / 京东 · https://huggingface.co/papers/2606.30626

### 问题与动机
On-policy distillation（OPD，在线策略蒸馏）让教师对「学生自己采样出的轨迹」做稠密的 token 级监督，能高效迁移能力。一个直觉的增强方向是给教师或学生「喂特权信息」（privileged information，比如额外的答案提示）来提升监督质量。但论文发现这会引入一个失败模式——「特权幻觉」（privilege illusion）：它混淆了两种差距，一是学生本该缩小的「可迁移能力差距」，二是只能模仿却永远无法复制的「信息不对称差距」。学生若去模仿后者，等于学一个自己永远达不到的捷径。

### 方法与核心创新
提出 DOPD：一种「优势感知的双重蒸馏」范式。它动态地在「特权教师」和「特权学生」两个策略之间路由 token 级监督——依据二者的优势差距（advantage gap）和相对概率，为每个 token 分配不同强度、不同目标、不同策略的监督：有的 token 从教师学、有的从学生自身学。这么做的目的，是在传递「可信、可复制的能力」的同时接收辅助信号，缓解特权幻觉。关键洞察是 token 级监督天然不均匀——只有一小部分 token 承载了「决定能力的关键信号」，逐 token 差异化对待才合理。

### 关键实验结果
在大语言模型（LLM）和视觉语言模型（VLM）两类设置上，DOPD 一致地超过 Vanilla OPD（朴素在线策略蒸馏）及其他对照方法。进一步在稳定性、鲁棒性、持续学习、分布外（out-of-distribution）任务上的实验都验证了其优越性。摘要以「consistently outperforms」的定性表述为主，未给出具体提升点数（摘要未明确，推断），最硬的信号是覆盖 LLM+VLM 两模态且在 4 类附加维度上均占优。

### 局限性与开放问题
最大遗憾是摘要通篇无量化数字，无法判断相对 Vanilla OPD 的提升幅度。「优势差距 + 相对概率」的路由规则引入额外超参与计算，其调参成本与对路由阈值的敏感度未讨论。特权学生本身若被特权信息带偏，双重路由能否完全隔离风险也存疑。

### 启发与应用前景
「特权幻觉」这一概念本身有价值——它精准点出了「给教师喂强提示反而害了学生」的隐蔽陷阱，对所有做蒸馏/知识迁移的团队都是警示。逐 token 差异化路由的思路可迁移到 RLHF、偏好蒸馏等场景。与本周 [6] Agents-A1、[7] LiveEdit 共同印证「在线策略蒸馏 + token 级精细监督」正成为能力迁移的主干路。摘要未提开源。

## 6. Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent
**👍 95** · 🏛 上海人工智能实验室 · https://huggingface.co/papers/2606.30616 · GitHub: https://github.com/InternScience/Agents-A1

### 问题与动机
主流认知是「参数越多越强」，但把万亿参数模型部署为 Agent 成本高昂。论文反其道而行，提出一个 35B 的 MoE（Mixture-of-Experts，混合专家，总参大但每次只激活一小部分）Agent 模型 Agents-A1，主张真正该 scale 的不是参数，而是「Agent 视野」（agent horizon，即完成任务所需的长程交互链条）。要解决的是：能否用 35B 的小盘子，在长程 Agent 任务上追平万亿参数模型。

### 方法与核心创新
从两个角度扩展 Agent 视野：一是扩展长程轨迹，二是扩展异构 Agent 能力。为此搭建「长程知识-行动基础设施」，把外部知识、动作、观测、验证器结果串起来，产出平均长度 45K token 的智能体轨迹。三阶段训练：① 全域 SFT 让底座对齐广泛的 Agent 行为；② 训练领域级教师模型捕获各领域专长；③ 提出「多教师、领域路由的在线策略蒸馏」（配合显著词表对齐），把六个异构领域的专长统一蒸馏进一个可部署的学生模型。核心是用蒸馏把「多个专家教师」压成「一个通才学生」。

### 关键实验结果
对比 1 万亿参数级的 Kimi-K2.6、DeepSeek-V4-pro，Agents-A1（35B）在多个长程 Agent 基准上取得领先或持平：SEAL-0 达 56.4、IFBench 达 80.6、HiPhO 达 46.4、FrontierScience-Olympiad 达 79.0、MolBench-Bind 达 56.8，并在 SciCode（44.3）、HLE（47.6）、BrowseComp（75.5）上保持高竞争力。用不到 1/28 的参数（35B vs 1T）在长程任务上追平万亿模型，是「视野 > 参数」最有力的证据。

### 局限性与开放问题
「追平 1T 模型」集中在长程 Agent 基准，在需要广博世界知识的短程任务上是否也能追平未展示——35B 的知识容量上限客观存在（摘要未明确，推断）。45K token 的超长轨迹对训练显存与推理上下文都是压力。三阶段 + 多教师蒸馏工程链条长，社区复现门槛高。

### 启发与应用前景
「scale horizon not parameters」为算力受限团队提供了一条极具吸引力的路线——不追万亿参数，而是把长程轨迹与蒸馏做深。多教师领域路由蒸馏的配方可迁移到其他「多专长合一」场景。与 [3] PAW「小模型顶大模型」、[5] DOPD「精细蒸馏」共振。代码 + 项目页已开源（418 stars，本周最高），是可直接上手研究的重量级资源。

## 7. LiveEdit: Towards Real-Time Diffusion-Based Streaming Video Editing
**👍 82** · 🏛 清华大学 / 香港科技大学 · https://huggingface.co/papers/2606.26740 · GitHub: https://github.com/cp-cp/LiveEdit

### 问题与动机

## 8. BlockPilot: Instance-Adaptive Policy Learning for Diffusion-based Speculative Decoding

### 问题与动机
投机解码（speculative decoding）用一个轻量「草稿模型」并行生成候选 token，再由目标模型验证，实现无损加速。基于扩散的投机解码更进一步——通过「块级扩散」（block-level diffusion）一次前向生成多个 token，达到 SOTA 加速。但现有方法用固定的推理块大小（block size），并假设所有输入都用同一套最优解码策略。论文指出这个假设是次优的：最优块大小其实因样本而异，且对加速性能起关键作用。

### 方法与核心创新
关键洞察有二：① 最优块大小随样本变化；② 这些最优值有清晰的局部结构——集中在训练块大小附近，从而把问题降维成一个低维、结构化的决策空间。基于此提出 BlockPilot：一个「样本自适应策略」，从预填充（prefilling，处理输入 prompt 的阶段）阶段的表示直接预测该样本的最优块大小。它把块大小选择建模成一个轻量策略学习问题，预测只在预填充后执行一次，因此能无缝集成、几乎零额外开销、即插即用。

### 关键实验结果
在 Qwen3-4B、温度 T=1 的设置下，BlockPilot 达到 5.92 的接受长度（acceptance length，每次验证平均被接受的 token 数，越大越省步数）和 4.20 倍加速。相比「固定块大小」的现有 SOTA，仅靠预填充后一次预测就把加速比推到 4.20×，且开销极小——性价比是其最大卖点。

### 局限性与开放问题
「最优块大小集中在训练块大小附近」是关键前提，若部署分布与训练分布差异大，这个局部结构假设可能失效（摘要未明确，推断）。策略只在预填充后预测一次、生成过程中不再调整，对生成中途难度剧变的长序列可能不够灵活。结果集中在 Qwen3-4B，更大模型上的增益未展示。

### 启发与应用前景
「用一个轻量策略预测最优解码超参」是把「静态超参」变「实例自适应」的通用思路，可迁移到 beam size、采样温度等其他解码决策。4.20× 加速对推理服务的吞吐成本是实打实的利好，即插即用降低了落地门槛。与本周整体的「效率优先」主线一致。代码已开源（60 stars）。

### 局限性与开放问题

### 启发与应用前景
「让模型用动作回答知识问题」是把纯语言评测接地到具身场景的巧妙设计，对诊断 VLA「学动作丢知识」的灾难性遗忘极有价值。「VQA 联合训练缓解遗忘」「知识峰值在中间层」两个发现，直接指导 VLA 的训练配方与架构改进（如在中间层加知识保留约束）。与 [11] Formalizing Latent Thoughts 共同指向「审计模型内部表示」的方向。代码 + 项目页已开源。

## 10. AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents
**👍 60** · 🏛 Alaya Lab / 上海交通大学 / 上海创智学院 / 南开大学 · https://huggingface.co/papers/2607.02255 · GitHub: https://github.com/AlayaLab/AgenticSTS

### 问题与动机
长程 LLM Agent 的记忆本质是「一份关于每个未来决策被允许看到什么的契约」。最简单的契约是把过去的观测、工具调用、反思全部拼进每个 prompt——这让历史易于访问，却也变成一锅「大杂烩」，任何单个记忆成分的作用都无法隔离分析。论文要解决的是：如何设计一个能干净地测量「不同记忆层各自贡献」的实验环境。

### 方法与核心创新
提出一个替代性的「有界契约」：每个决策都从一条全新的用户消息出发，该消息由「类型化检索」（typed retrieval，按类型分类取回相关记忆）拼装而成，不再把原始的跨决策对话记录拼进去。这样 prompt 无论运行多长都保持有界，且任何单个记忆层都能被单独消融（ablate）分析。测试床选在《杀戮尖塔 2》（Slay the Spire 2）——一个规则封闭、随机的卡牌构筑游戏，一局需要数百个战术与战略决策，非常适合考验长程记忆。

### 关键实验结果
参照系很硬：一个公开在线基准上，前沿 LLM 在最低难度、五种配置下「零胜局」，而开发者报告的人类胜率是 16%——任务难但未饱和。在自家 harness 里，固定-A0 消融显示，当启用「触发式战略技能」时差异最大：无存储基线胜 3/10，加上技能层后胜 6/10。但在此样本量下（Fisher 精确检验 p≈0.37），该对比只是方向性的、不具统计显著性。论文发布了 298 条完整轨迹（带条件标签、冻结的记忆/技能快照、prompt 记录、分析脚本）。

### 局限性与开放问题
论文相当诚实：p≈0.37 意味着「技能层有效」尚未通过统计检验，3/10 vs 6/10 只是方向性信号，样本量（各 10 局）明显不足。跨底座探测和公开累积上下文基线被明确定位为「操作性对比」而非受控实验。结论能否外推到《杀戮尖塔 2》之外的长程任务未验证。

### 启发与应用前景
「有界契约 + 类型化检索」把 Agent 记忆从「无限拼接的大杂烩」变成「可逐层消融的受控变量」，这套方法论本身比具体胜率更有价值——它给「记忆层到底有没有用」提供了可复现的实验范式。298 条带标签轨迹 + 分析脚本对研究长程记忆的社区是现成资源。作者对统计不显著性的坦诚值得称道。代码 + 项目页已开源（106 stars）。

## 11. Formalizing Latent Thoughts: Four Axioms of Thought Representation in LLMs
**👍 60** · 🏛 英属哥伦比亚大学 · https://huggingface.co/papers/2606.27378 · GitHub: https://github.com/fard-lab/formalize-thoughts

### 问题与动机
现有对 LLM「隐式思维表示」（latent thought representation，模型内部承载推理的中间表示）的评估，都把「表示质量」和「模型容量」混在一起：失败到底该归咎于表示本身不好，还是处理它的模型不行，无法分辨。论文要解决的是：能否设计一套「独立于下游基准分数」的评估，直接在表示上计算，揭示那些被基准准确率掩盖的表示缺陷。

### 方法与核心创新
提出一个公理化评估框架，形式化四条功能公理并各定义一个可量化指标，全部直接在表示上计算、不依赖下游准确率：① 因果性（Causality，表示是否真的驱动了输出）；② 最小性（Minimality，是否只编码必要信息）；③ 可分性（Separability，不同思维能否被区分开）；④ 稳定性（Stability，表示是否稳健）。核心价值是把「表示好不好」从「模型答对没」中彻底解耦出来，让缺陷可归因。

### 关键实验结果
在 23 个推理任务（如空间推理、事实问答）上审计开源权重 LLM，得到三个尖锐结论：① 没有任何候选模型同时满足全部四条公理；② 表示能可靠区分「任务类型」，却无法区分「同一任务内的两个不同问题」——粒度严重不足；③ 表示编码的信息几乎没有超出输入 embedding 里已有的内容——即「思考」没带来新信息。更关键的是，这种失败在稠密模型、推理蒸馏模型、RL 训练模型三类家族上一致出现，说明缺口是「结构性」的，而非模型规模或训练方法的问题。

### 局限性与开放问题
四条公理是否「完备」（是否还有未覆盖的关键维度）本身是开放问题。「表示无法区分同任务内两问题」的结论依赖所选的 23 个任务与探测方法，换一套探测器是否结论不变未知（摘要未明确，推断）。框架诊断出了病，但未给出「如何改进表示」的处方。

### 启发与应用前景
「四公理」把「模型到底在不在真思考」从玄学讨论拉到可量化审计，对可解释性研究是有力工具。「结构性缺陷、跨训练范式一致」的发现给「链式思考=真推理」泼了冷水，提示当前架构的隐式表示可能存在根本瓶颈。与 [9] VLA 知识探测共同代表本周「审计内部表示」的方向。代码 + 项目页已开源，可 follow 的切口是把四公理用作训练时的正则约束。

## 12. Scenes as Objects, Not Primitives: Instance-Structured 3D Tokenization from Unposed Views

### 问题与动机

### 局限性与开放问题

### 启发与应用前景
「让物体成为 3D 表示的原生接口」直击当前 3DGS「一堆无意义高斯球」难以编辑操控的痛点，对 3D 内容创作、机器人抓取（需要物体级理解）、AR 场景交互都有直接价值。检索复杂度随实例数而非图元数增长，对大规模 3D 资产库检索是实质利好。与本周 [1] Orca、[13] PhysisForcing 共同构成「3D/世界表示」主题。项目页已放出。

## 13. PhysisForcing: Physics Reinforced World Simulator for Robotic Manipulation
**👍 51** · 🏛 北京大学 / 英伟达 · https://huggingface.co/papers/2606.28128 · GitHub: https://github.com/DAGroup-PKU/PhysisForcing

### 问题与动机
视频生成模型正成为「具身世界模拟器」的有力范式——让机器人在生成的视频里「想象」操作结果。但无论是通用视频生成器还是用机器人数据微调的模型，都仍会产出物理上不合理的操作：运动轨迹不连续、机器人与物体的交互前后不一致，这严重限制了它们作为世界模拟器的可靠性。论文通过大量实验定位到物理不稳定主要来自两个因素：运动中物体的形变，以及交互实体间不合理的时空关联（尤其在接触发生时）。

### 方法与核心创新
提出 PhysisForcing：一个可扩展的训练框架，通过把监督聚焦到「物理信息密集的区域」来强化物理一致性。它由两个损失组成：① 像素级轨迹对齐损失——用参考点轨迹去监督 DiT（Diffusion Transformer，扩散 Transformer，当前主流视频生成骨干）的特征，约束运动连续；② 语义级关系对齐损失——把 DiT 特征与「从一个冻结的视频理解编码器提取的区域间关系」对齐，约束接触交互的合理性。核心思路是「哪里物理容易崩，就把监督砸到哪里」，而非平均用力。

### 关键实验结果
在 R-Bench、PAI-Bench、EZS-Bench 上，PhysisForcing 一致提升具身视频生成：在 R-Bench 上把 Wan2.2-I2V-A14B 和 Cosmos3-Nano 两个底座分别提升 22.3% 和 9.2%（相比朴素微调的增益为 7.1% 和 3.7%），其中 Cosmos3-Nano 变体拿到最佳总分。更关键的是当作世界模型用时：在 WorldArena 动作-规划器协议下，把闭环成功率从 16.0% 拉到 24.0%（相对提升 50%），并进一步改善下游策略成功率——说明物理对齐的视频模型能给机器人操作提供更强的表示。

### 局限性与开放问题
语义级关系依赖一个「冻结的视频理解编码器」，其质量直接决定关系监督的上限——编码器本身的偏差会传导进来（摘要未明确，推断）。22.3% 的提升在 Wan2.2 上显著，但 Cosmos3-Nano 上仅 9.2%，说明增益对底座敏感。闭环成功率 24.0% 绝对值仍低，离可靠部署有距离。

### 启发与应用前景
「把监督聚焦到物理易崩区域」是提升生成物理一致性的务实思路，对机器人仿真、sim-to-real、具身策略预训练价值直接——闭环成功率 16%→24% 证明「物理对齐的视频 = 更好的机器人表示」这一链路成立。像素级轨迹 + 语义级关系的双损失设计可迁移到其他需要物理合理性的视频任务。与 [1] Orca 同属「世界模型」主题、与 [12] 同属 3D/具身。代码 + 项目页已开源（83 stars）。

## 🗺️ 趋势洞察

### 1. 世界模型从「预测下一帧」走向「预测下一个状态 + 物理一致 + 物体级结构」
**涉及论文**：[1], [12], [13]
**核心观点**：本周热度第一（[1] Orca，307 赞）标志「世界基础模型」路线的系统化。Orca 把建模目标从「下一个 token/帧/动作」升级为「下一个状态」（Next-State-Prediction），用 125K 小时视频 + 1.6 亿事件标注学一个统一世界隐空间，冻结主干即可读出文本、图像、动作三种下游。PhysisForcing（[13]）则从另一端补上「物理一致性」这块短板——把监督聚焦到「运动形变、接触交互」等物理易崩区域，在 R-Bench 上提升 22.3%，把作为世界模型的闭环成功率从 16% 拉到 24%。Scenes as Objects（[12]）从表示结构切入，让「物体」而非「一堆高斯图元」成为 3D 场景的原生接口，直接解锁实例级编辑与检索。三者共同信号：2026 年的世界模型不再满足于「画得像」，而追求「状态可预测、物理可信、结构可操控」——这正是具身智能对仿真沙盒的真实需求。

### 2. 在线策略蒸馏（OPD）成为能力迁移的主干路，并走向 token 级精细化
**涉及论文**：[5], [6], [7], [3]
**核心观点**：蒸馏是本周出现频率最高的技术底座，且都在往「更精细、更结构化」演进。DOPD（[5]）提出「特权幻觉」概念，按优势差距逐 token 在特权教师与特权学生间路由监督，指出「只有一小部分 token 承载关键能力信号」。Agents-A1（[6]）用「多教师、领域路由的在线策略蒸馏」把六个异构领域专家压成一个 35B 学生，追平万亿参数模型。LiveEdit（[7]）用「三阶段蒸馏」把双向教师的编辑能力迁到单向流式学生，做到 12.66 FPS 实时。PAW（[3]）则把蒸馏推向极致——把 prompting 一次性「编译」成可离线复用的适配器，0.6B 学生追平 Qwen3-32B。共同点：教师→学生的能力迁移正从「整体模仿」转向「token 级 / 领域级 / 一次编译」的差异化蒸馏。

### 3. 「参数不是唯一杠杆」——多条路径证明小模型可顶大模型
**涉及论文**：[3], [6], [4], [8]
**核心观点**：本周多篇论文集体挑战「参数越多越强」的默认假设，从不同维度找替代杠杆。Agents-A1（[6]）主张 scale 的是「Agent 视野」（45K token 长程轨迹）而非参数，用 35B 追平 1T 的 Kimi-K2.6/DeepSeek-V4-pro（参数差 28 倍）。PAW（[3]）用「一次编译成适配器」让 0.6B 顶 32B（差 50 倍），还能在 MacBook M3 上 30 tokens/s 离线跑。Dockerless（[4]）不加参数而是「省去 Docker 环境」，用智能体探索代替执行验证，把编码 Agent 后训练成本从主要瓶颈变为可省项。BlockPilot（[8]）用一个轻量策略预测最优块大小，几乎零开销就把投机解码加速到 4.20×。共同信号：能力/效率的增量正越来越多地来自「训练配方、编译、环境、解码策略」等参数之外的维度。

### 4. Agent 的「元认知」缺口被集中审视——知道何时停、记什么、想什么、还懂不懂
**涉及论文**：[2], [10], [11], [9]
**核心观点**：本周多篇论文不再问「Agent 能不能做对」，而是审视 Agent 的自我认知与内部表示。Agentic Abstention（[2]）揭示 Agent「不知道何时该停手」——在 28,000 任务上发现更强的模型有时反而更不会及时弃权，CONVOLVE 把 Llama-3.3-70B 的及时召回从 26.7 提到 57.4。AgenticSTS（[10]）审视「记什么」——用有界契约把记忆变成可逐层消融的受控变量（并诚实报告 p≈0.37 的不显著）。Formalizing Latent Thoughts（[11]）审视「想什么」——用四条公理证明没有模型能全部满足，且缺陷是跨训练范式的结构性问题。Does VLA Know Basics（[9]）审视「还懂不懂」——发现 VLA 微调后知识在上层衰减、VQA 联合训练能缓解遗忘。共同点：Agent 研究正从「能力评测」深入到「元认知与内部表示的审计」。

### 对比与张力
- **「生成/想象」补全信息 vs 物理与真值可信度**：Orca（[1]）从视频想象状态转移、Scenes as Objects（[12]）从无位姿图像想象 3D 结构、PhysisForcing（[13]）生成机器人操作视频——都靠生成补全不可直接观测的信息。但 [13] 恰恰揭示生成模型「物理容易崩」，闭环成功率仅 24%，说明「想象力」与「物理可信度」之间的张力尚未消解。
- **诚实的负面结果 vs 追求 SOTA 的正面叙事**：AgenticSTS（[10]）坦承 p≈0.37 不显著、只是方向性信号，Formalizing Latent Thoughts（[11]）直接给出「没有模型满足全部四公理」的负面结论——这两篇的价值在于「诚实的诊断」，与本周多数论文「刷出 SOTA」的正面叙事形成有益对照。
- **精细化 vs 可复现性**：DOPD（[5]）的逐 token 优势路由、Agents-A1（[6]）的三阶段多教师蒸馏都走向高复杂度以求性能，而 PAW（[3]）「一次编译离线跑」、BlockPilot（[8]）「即插即用零开销」则主打简单可部署。社区在「堆栈式精细 SOTA」与「优雅可复现」间的张力持续存在。
- **更强模型 ≠ 更好行为**：[2] 发现更大/更强的模型有时更不会及时弃权，[9] 发现更强 VLM 微调成 VLA 后知识反而丢失——两处都提示「能力上限」与「行为可靠性/知识保留」并非同向增长，是值得警惕的反直觉信号。

### 值得关注的研究方向
1. **世界模型的「状态-物理-结构」三位一体**：[1] 攻状态预测、[13] 攻物理一致、[12] 攻物体结构，各补一面。把统一状态隐空间、物理对齐损失、实例级结构化表示整合进单一世界模型，是具身仿真沙盒的明确下一步。
2. **token 级 / 领域级差异化蒸馏的统一理论**：[5] 的优势感知路由、[6] 的领域路由、[3] 的一次编译各自成体系，但缺乏统一框架来回答「什么信号该从教师学、什么该从学生学、什么该编译固化」。
3. **Agent 元认知的可量化审计**：[2]（何时停）、[10]（记什么）、[11]（想什么）、[9]（还懂不懂）分头突破，把「弃权、记忆、隐式表示、知识保留」统一到一套可测量的「Agent 自我认知」基准，将是可靠 Agent 落地的前提。
4. **参数之外的效率杠杆工程化**：[6] 视野、[3] 编译、[4] 环境、[8] 解码策略——把这些「非参数杠杆」组合进单一系统（如「长视野训练 + 编译离线部署 + 自适应解码」），可能带来远超单纯扩参数的性价比。
5. **生成式补全的物理/真值可信度量**：[1] / [12] / [13] 共享「生成不可观测信息」的范式，而 [13] 已量化「物理不合理」的代价。建立「何时是有用想象、何时是有害幻觉」的可验证物理度量，是世界模型从「好看」走向「可用」的关键。
